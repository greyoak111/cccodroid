# 权限说明

[English](permissions.md) | 中文

cccodroid 申请的权限不少。这一页逐个说明每个权限拿来干什么、什么时候才会问你、不给会怎样。

先说最要紧的一点：**Claude 在 cccodroid 里能以这个应用的身份执行任意命令**，这本来就是它的用途。所以应用拿到的每一项权限，Claude 跑的命令也都拿得到。给权限之前，请按这个前提来判断。

## 一览

| 权限 | 用来做什么 | 什么时候问 | 不给会怎样 |
|---|---|---|---|
| 网络（`INTERNET`、`ACCESS_NETWORK_STATE`） | 连模型接口、下载 Claude Code 和工具包；看当前连的是不是 Wi-Fi（定时任务的「只在 Wi-Fi 下」） | 不用问，装上就有 | 没法用 |
| 存储（`READ/WRITE_EXTERNAL_STORAGE`，36 版另要「所有文件访问」`MANAGE_EXTERNAL_STORAGE`） | 读写 `/sdcard/cccodroid`：交付给别的应用的 APK、截图、离线工具包；也让 Claude 能处理你放在共享存储里的文件 | 28 版首次打开时；36 版问一次，带你去系统设置 | 能用，产物只留在应用私有目录，别的应用看不到 |
| 通知（`POST_NOTIFICATIONS`） | 后台跑完、定时任务结果、需要你确认的操作 | 首次打开 | 能用，只是在后台时收不到提醒 |
| 锁屏验证（`USE_BIOMETRIC`） | 把需要长期保存的安全开关（后台保活增强、设备工具、特权命令免确认、网页调试）用锁屏再确认一遍 | 打开受保护的开关时（系统锁屏确认，不是权限弹窗） | 开关只在这次运行有效，重启应用后要重新打开 |
| 前台服务、保持唤醒（`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_SPECIAL_USE`、`WAKE_LOCK`） | 让网关在你切走、锁屏后继续把这一轮跑完 | 不用问 | 不能拒绝；没有它，切到后台几秒就会断网、中断 |
| 忽略电池优化（`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`） | 让系统省电策略别冻结后台的长任务 | 你在设置里点「后台运行」时 | 长任务、定时任务在锁屏后可能被系统停掉 |
| 精确闹钟、开机广播（`SCHEDULE_EXACT_ALARM`、`RECEIVE_BOOT_COMPLETED`） | 定时任务到点叫醒网关；开机后重新激活 Shizuku（只在你配对过、且在设置里打开了自动激活时，默认关） | 不用问 | 定时任务可能晚一点才跑；开机后要手动激活 Shizuku |
| 安装应用（`REQUEST_INSTALL_PACKAGES`） | 应用内更新 cccodroid；把 Claude 在本机打包好的 APK 装上 | 第一次装的时候，系统让你在设置里允许 | 更新要自己去下载安装 |
| 设置闹钟（`SET_ALARM`） | 设备工具里「帮我定个闹钟」：交给系统时钟应用 | 不用问 | 设备工具没法定闹钟 |
| 全屏通知（`USE_FULL_SCREEN_INTENT`） | 配对 Shizuku 时，让带输入框的配对通知一直停在屏幕顶部 | 不用问 | 配对通知可能自己收起，要下拉通知栏去找 |
| Shizuku（`moe.shizuku.manager.permission.API_V23`） | 可选。拿到 shell 身份（uid 2000），用于免确认安装、给自己开所有文件访问、设备工具 | 你在设置里主动开启时 | 这几样功能用不了，其余照常 |
| 写安全设置（`WRITE_SECURE_SETTINGS`） | 只能经 Shizuku 授予。用来在重启后自己打开无线调试、重新激活 Shizuku；按需开关 cccodroid 自己的无障碍服务 | Shizuku 授权时一并给 | 每次重启要手动激活 Shizuku；无障碍要自己去系统设置开 |

## 没有申请的

相机、麦克风、定位、通讯录、短信、通话记录都没有申请。

拍照（输入栏「＋」里的拍照）是交给系统相机应用拍完再传回来，所以不需要相机权限。

## 三项重权限，单独说

**所有文件访问。** 给了以后，应用和 Claude 能读写整个共享存储，不只是 `/sdcard/cccodroid`。要是你的照片、文档也放在共享存储里，Claude 跑的命令同样碰得到。不想这样就别开，只用应用私有目录。

**Shizuku 与写安全设置。** 这是 shell 身份，能做的事比普通应用多得多，比如装卸应用、改系统设置。cccodroid 用它做的事都记在设置里 Shizuku 那一栏的「特权命令记录」里。设备工具（让 Claude 截屏、点屏幕、开关系统设置）和无障碍服务**默认都是关的**，要你自己打开；无障碍闲置一段时间会自动关掉。

有两点要心里有数。第一，授权给的是 cccodroid 这个应用，不是某一个按钮：应用里跑的任何代码，包括 Claude 执行的命令、你装的组件，都能经应用转一手拿到 shell 身份；开机自动激活又会让这份权限一直延续下去。所以开了 Shizuku，就等于信任在 cccodroid 里跑的一切。为了让偷偷借用至少有动静：经 `priv` 跑的命令，只有带服务名的 dumpsys、pm list、settings get 这类查看命令，以及内存管家要用的停止应用、限制应用后台（am force-stop / stop-app / set-bg-restriction-level）直接执行，其余（装卸应用、改设置、截屏、模拟点按、读全机日志 logcat、读共享存储里的文件等）都会先在 cccodroid 里弹窗等你点允许，cccodroid 不在前台时直接拒绝。这是一道提醒，不是隔离墙。不需要了，到 Shizuku 里撤销授权（自动激活默认关，打开过的话也关掉）。第二，特权命令记录存在应用自己的目录里，是给你查看用的，不是防篡改的审计日志：在应用里跑的代码本身就有办法改它。

**安装应用。** 系统每次都会弹确认页，你点了才装。有 Shizuku 时可以免确认，这种情况同样会记进特权命令记录。
