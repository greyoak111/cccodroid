# PDF 工具箱

文件面板中的「PDF 工具箱」提供本地合并、提取页面、拆成单页、旋转、压缩和转图片。PDF 查看器顶栏也有入口。处理不经过 Claude，不需要模型额度，原文件保持不变。

## 使用

1. 在「扩展 → 可选组件」安装 **PDF 工具箱（pdf-tools）**。压缩还需要基础工具包中的 Ghostscript；缺失的程序会在工具箱中列出。
2. 在文件面板选中 PDF，或多选几份后点击「PDF 工具箱」。也可以在工具箱中点击「选择 PDF…」，通过系统选择器将文件导入工作区。
3. 选择操作。合并按列表顺序进行，可以上下移动；提取、拆分、旋转和转图片的页码支持 `1-3,5`，留空表示全部。重复页码只处理一次，范围必须从小到大；页码段按填写顺序输出。
4. 填写一个**尚不存在**的输出文件夹的完整路径。结果文件命名为 `result.pdf`、`page-0001.pdf` 或 `page-1.png` 等，图片序号表示选页后的顺序。
5. 点击「开始处理」。完成后可预览、分享单个结果，或前往结果文件夹。压缩使用 pdf-shrink 的 screen / ebook / printer 档；结果变大时会明确提示，原文件仍然保留。

关闭工具箱不停止后台任务；重新打开可以查看本次运行的结果并取消尚未结束的任务。进程重启后不恢复任务列表，已经保存的结果仍可通过文件面板访问。

## 限制

- 一次一个任务；合并 2–20 份 PDF，其他操作一次一份。输入合计最多 256 MB。
- 页操作和合并最多处理 1000 页；转图片最多 100 页，72 / 150 DPI、PNG / JPEG，长边封顶 2048 像素。
- 单个工具运行最多 2 分钟，整个任务最多 5 分钟。输出最多 512 MB，剩余存储不足 64 MB 时停止；输出与磁盘空间每秒检查一次，极短时间内的峰值可能超过阈值。
- 不支持输入密码。加密、损坏或工具无法解析的 PDF 会失败，源文件不变。
- 不提供 OCR、PDF 转 Word、签名编辑。旋转、提取和重写可能使原数字签名失效，需保留原件。

## 开发验证

后端只使用已有组件的 qpdf、pdftoppm、pdf-shrink；不新增应用依赖或构建步骤。新路由位于既有网关鉴权之后，并复用文件路径限制与子进程运行标记。命令参数走 argv，输入拷贝到独立工作目录，结果文件夹排他创建。

代码 PR 按 CONTRIBUTING.zh-CN.md 要求补齐 Android 真机测试；桌面测试不能代替 Android 工具包、WebView 和系统文件选择/分享验证。
