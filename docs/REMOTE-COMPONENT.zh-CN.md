# 可选远程会话托管（实验性）

## 产品与权限边界

远程会话托管是「扩展 → 组件」中的可选功能，组件 ID 为 `remote-session`。原设备主动选择一个会话并邀请已配对手机；手机可查看该会话、逐项处理原请求、发送普通文字和单独请求停止。模型、工具、项目文件和原任务仍在原设备执行。

设备登记、双方配对、指定会话授权是三层不同的权限。在线不等于配对成功，配对不开放会话，接受邀请不批准工具，收回授权不停止原任务。远程文字不带附件，不作为本地斜杠命令执行，不提供文件浏览、任意路由或终端。

中转是独立部署的可选服务，只转发端到端通道的不透明字节和有限路由元数据，不执行模型或工具。上游项目不替用户提供托管服务器。会话原有的代码、日志和敏感内容可能已在正文里；用户应在授权前确认传输范围。

## 宿主和组件

宿主需要 `hostApi.remoteSession = 1`：

- 宿主提供严格的本机 HTTP schema 与鉴权、原执行/权限/回执适配、Android 私有 IPC/Keystore/元数据通知、固定角色页面挂载器。
- 组件提供远程协议、配对、内部 TLS、授权数据投影、控制协调、手机状态管理、中转连接和界面。
- 宿主 APK 不携带组件业务 JS/CSS；未安装或未启用时不创建远程运行时、不开中转连接、不读会话、不显示托管入口。
- 不用组件安装脚本覆盖应用核心文件，不改变现有桥或模型接口。

组件文件只落在 `usr/share/cccodroid/components/remote-session/` 和 `usr/libexec/devkit/components/remote-session/`。业务入口位于内容寻址的 `releases/<assetVersion>/`；清单及逐文件哈希验证后才加载，升级不复用旧版本模块缓存。

## 生命周期与错误结果

安装、升级和卸载沿用签名索引、归档 SHA-256、MANIFEST 和工具包匹配。当前构建脚本只产出本地候选，不能冒充市场已签名发行；不关闭任何索引或证书校验。

停用、卸载和升级先禁止新控制并撤销旧授权，再清理连接、订阅、通知、手机内容和草稿。原任务不受这些动作停止。身份、配对与配置可保留以便明确再启用，但旧授权和旧命令不能复活。离线无法确认对端是否已收到撤权；本地撤权不等待对端在线。

控制命令使用稳定 commandId，区分 `received / applied / rejected / unknown`。只有原设备的实际处理证据能成为 applied；中转 ACK、点击按钮或超时都不是成功。断线时禁控、不自动审批、不排队自动发送、不自动重发结果未知的命令。恢复后先重新核对完整授权、当前运行和原请求版本。

## 固定接口

`GET /api/components/remote-session/status` 返回 `absent / disabled / active / incompatible / error / retiring`。active 包含内容哈希 `assetVersion` 和随机运行实例 `activationId`；同版本快速停启也换实例，旧界面必须清理而非沿用草稿或控制资格。

`POST /api/components/remote-session/enable` 与 `disable` 只接受空 JSON 对象。业务 UI 仅从同源 `ui.js`、`ui.css` 加载，必须带精确版本查询参数；不接受公网脚本或任意组件入口路径。

所有 `/api/remote/*` 业务请求必须固定创建时的 `activationId`：设置 API 使用 `x-cc-remote-activation` 请求头，手机 fetch/SSE 使用 `activation` 查询参数。旧实例、缺失或不匹配值返回 `COMPONENT_VERSION_MISMATCH`，迟到请求不能转投新实例。该值是实例身份，不是认证凭据，也不代替既有本机鉴权；公开旧值不授予查看或控制权限。

组件列表按选中构建携带可选 `hostApi` 要求。显式非法/未知能力不得当作“无要求”忽略。旧客户端不会因为索引多了一个字段就自动实现能力门禁：正式发行前仍须维护者确定并验证旧客户端分发隔离。

## 验证与发行状态

隔离测试使用临时 HOME/PREFIX、合成设备、真实本地 TLS/中转以及受控假 CLI；它们不调用真实模型，不读取用户数据。Headless Chromium 不代表 Android WebView、Keystore、锁屏、OEM 后台策略或系统通知已完成真机验证。
