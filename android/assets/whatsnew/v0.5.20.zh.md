这一版修了群里和 GitHub 上报的三个问题。

## 权限与计划

- 全局开着「全部放行」时，Claude 自己进了计划模式，批准计划会把权限降成「逐项确认」或「自动接受编辑」。现在计划卡多了一个「批准，按当前模式执行」，只把这一轮带回原来的模式，不改你的全局设置。
- 批准权限请求时不能再顺带把模式放宽；要放宽，得到设置里切，那里会先确认。

## 步骤与图片

- 一组步骤中间夹着图片时，点组头收不起来，现在能收了。
- 命令输出里提到的图片读不到时（比如只有 root 能读的 `/data/adb`，或者文件其实不在），不再留一行打不开的路径，也不会因此把步骤组一直撑开。

## 组件

- OpenAI API 本地协议桥（openai-bridge）更新到 r14：有的上游不认推理强度参数，只回一句 `400 Invalid request payload`，整轮失败。现在遇到这种情况会去掉这两个参数重发一次，成功后记住，之后不再带（#84）。在「组件」里更新即可。
