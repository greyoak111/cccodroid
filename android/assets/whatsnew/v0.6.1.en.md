This release is mostly about privileged commands interrupting you less. It also fixes a few problems in the sidebar and in the background.

## Privileged commands

- Until now, every privileged command needed you to come back to cccodroid and tap Allow, and a task running in the background stopped as soon as it hit one. There are now three ways to loosen this, from narrowest to widest:
  - "Allow, don't ask again for this command for 10 minutes" covers only that exact command.
  - Tick "Allow all later privileged commands in this session" in the prompt, and that session won't be asked again and can keep going in the background. It resets when the app restarts.
  - Settings → Device & permissions → "Stop confirming privileged commands one by one (at your own risk)" runs every privileged command directly. A disclaimer is shown when you turn it on.
- Commands that touch cccodroid itself or Shizuku / Sui are caught and confirmed where possible, but not every form can be caught (for example, one hidden in a script file).
- Sui is supported (#112): if you already have Sui, grant cccodroid access in Sui and you don't need Shizuku.

## Sidebar and sessions

- Sessions filed under Misc no longer disappear from the sidebar while they are pinned, running, or waiting for your confirmation.
- Long sessions could be wrongly filed under Misc by the AI. Now, if a session the AI put in Misc gets compacted once or grows past 512 KB, it goes back to its normal group automatically. Sessions you moved there yourself stay put.
- Local paths written as `[path](file:///…)` links in replies used to show up as raw text you couldn't tap. They now open in the viewer. The model is also told to write paths as plain text instead of wrapping them in links.

## Background

- Swiping cccodroid away in Recents now closes it: if nothing is running, the gateway stops and the ongoing notification goes away, instead of restarting itself and getting stuck on "Starting…". If a turn is running, it stops after the turn finishes. Scheduled tasks are still woken by a system alarm when they're due.

## Other

- Fixed several security issues.
- The work island now receives checklist progress (done / total), so it can draw a segmented progress bar (#111).
- Fixed a few gateway tests that failed in CI (#113).
- The in-app help now covers the new features from this release and the last one.
