This release fixes several security issues, asks you to allow Shizuku activation in a system dialog, and fixes a large batch of problems found in reviews and everyday use.

## Security

- Fixed several security issues.
- Activating Shizuku and turning on "activate automatically at boot" now first show a native dialog, and only go ahead when you tap Allow.
- A few settings that need your consent (keep-alive boost, running privileged commands without asking, device tools, WebView debugging, activating Shizuku at boot) are now stored differently. **Turn them on once more after updating.**

## Fixes

- After running for a long time, the gateway log no longer keeps warning about too many listeners (they piled up while replaying the event stream).
- Stopping a turn while `/model`, `/effort` or `/autocompact` is still waiting for the model list no longer changes your settings; it replies that it stopped and nothing changed.
- When a running session is opened from an old chapter or a bookmark, "View" on the confirmation bar first jumps back to the latest and then scrolls to the card.
- A turn with only background tasks left still counts toward the parallel limit, so a new session is no longer told the previous turn hasn't finished.
- Replies received again after a dropped connection show the time taken based on when the turn actually ended.
- When a scheduled task's provider is left empty (follow the project), the model list follows the selected project's provider and changes with it. After provider settings change, old model lists are no longer reused.
- "Other providers" on the Usage page no longer lists the main card's provider again. Signing out clears the usage figures and the weekly quota summary.
- If a file you're editing is renamed, moved or deleted, saving asks whether to save a copy under the original name instead of quietly creating a new file.
- Files opened from project details use the same viewer as the file browser.
- If the source file is saved while an Office conversion is running, the freshly converted PDF still opens.
- The commit message is kept after Select all and after viewing a diff. In a repository with no commits yet, the diff shows the working tree as it is now.
- Diffs, history and commit details no longer fail in sha256 git repositories.
- When sharing, files with apostrophes, tildes and similar characters in the name get the right type.
- If the system reclaims the app while you're choosing where to "Save to", the file is still saved when you come back, with no empty file left behind.
- A brief wireless-debugging disconnect is no longer treated as an unpaired device, so automatic activation isn't switched off.
- Websites in the in-app browser are no longer blocked by the HTML preview's offline switch.
- Scheduled tasks: tasks created during the repeated hour when daylight saving ends aren't counted as missed; queues restored after a restart finish and record usage normally; a successful run cancels pending failure retries; "Skip the next run" also applies to missed runs.
- Attachments uploaded to a new session no longer end up in an empty draft if you switch away.
- A saved prompt close to the size limit no longer disappears right after saving.
- If UI customization or appearance can't be saved, you're told, instead of the change only lasting until restart.
- Importing two fonts back to back no longer applies the interface font to replies.
- While a component is downloading or being verified, the devkit modules it needs can't be removed. Packages you installed by name with `pkg install` are no longer removed along with another package.
- Cancelling a model download no longer lets the file through once verification finishes.
- Switching the same provider to another account's key no longer records the balance difference as spending.
- Custom component descriptions containing colons now produce a valid skill file.
- Lineage: layout carries over across projects; date ticks are right around daylight saving changes; sessions moved into a project no longer show the old location; a last line without a newline is still read.
- Undoing deletes, pinning, renaming and similar changes are now written to disk atomically.
- Interjections and ⚡ now check the run settings too.
- Filled in a batch of missing translations, and fixed the language dropdown and Spanish plurals.
- Toolchain self-test: when the network can't reach Google, or reaches github.com only some of the time, this is now reported as a network limitation instead of a broken tool.
- The help page now lists the Material appearance.

## Other

- The app package now includes the LGPL license and source notice for the glibc loader.
- The docs now include test results from a OnePlus Ace 7 Pro (Android 17).
