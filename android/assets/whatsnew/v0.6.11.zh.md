这一版补上原本就该随 0.6.10 一起发的压缩包功能，并修了 0.6.10 发出后大家反馈的几个问题。

## 新功能

- 文件管理器支持压缩包：点开先像文件夹一样一层层浏览，不用解压；包里的单个文件可以直接预览；可以解压到旁边的同名文件夹或你选的目录，也可以多选文件打成 zip / 7z / tar。
- 支持 zip（含 jar、apk）、7z、rar（含分卷）、tar 及 tar.gz / xz / zst / bz2、单个 .gz / .xz；Windows 打的中文文件名 zip 自动认出 GBK；加密包输入密码就能解，密码不保存。
- 7-Zip 26.06 随安装包自带，不用另装。
- 设置 → 排障里新增「恢复初始设置」：配置改坏了、每轮都被拒或不出回答、自己救不回来时，一键把 Claude Code 的用户级配置（CLAUDE.md、技能、插件、钩子、MCP、记忆）、cccodroid 设置和 shell 启动文件恢复成刚装好的样子。原来的都挪进 `~/.ccapp-reset` 留底，不删；会话记录、工作区、工具包不动，密钥默认保留。网关起不来时，在启动页「我卡住了」和等待页上也能找到它。

## 修复

- 上下文用量条在上下滑动时不再被挤到顶栏底下（整页不再跟着滚）。
- 系统提示不再放在 Claude Code 的命令行参数里：以前会话里跑 `ps` 会看到整段系统提示，模型会把它误当成外来的注入。
- 网关自己的运行库需要联网取回时，启动页会显示下载进度、速度和剩余时间，并说明断了会接着下；取回期间不会再到点切到打不开的界面。
- 解压可以直接解到工作区本身。

感谢群友们在 0.6.10 发出后第一时间反馈问题、发来截图和诊断包。
