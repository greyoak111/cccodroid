This release builds the work island into the app itself (native Live Updates on Android 16+, with a floating capsule fallback on older versions), lets you share files larger than 512 MB without copying, adds a read-only project memory viewer, and fixes a batch of concurrency 502s, event-loop blocking, the "Stream closed" permission-confirmation race, and other security and stability issues.

## Work island (built in)

- **No companion app needed**: work status shows up directly in the system live notification / dynamic island. Android 16+ uses native Live Updates and adapts to Honor Magic Capsule, ColorOS Fluid Cloud, HyperOS Super Island, etc.; on older versions or devices that don't allow promoted notifications, an optional touch-through floating capsule can be enabled; otherwise a normal same-card progress notification is used.
- **Self-check in settings**: live status of notification and overlay permissions, one-tap jumps to system settings, and a 10-second preview; refreshes when you return to the app.
- Collapses 8 seconds after completion, taps through to the matching session, and shows elapsed time plus TodoWrite progress.

## Large-file sharing

- **512 MB limit removed**: sharing a file from the workspace or /sdcard now hands out a zero-copy read-only grant, so the system share sheet opens in milliseconds without copying the file or using extra space. Grants last 24 hours and survive an app restart, so slow cloud uploads keep working.
- Security is unchanged: credentials, private directories and hard links are still blocked; if the original path is replaced with a symlink after the grant, reads are refused.

## Project memory

- The project "Memory → View" action is now an in-app read-only viewer: lists memory files, renders Markdown, and can copy the full text. There is no edit or delete action, and no local or remote images are loaded.
- The general file API still returns 403 for the private memory directory — the guard was not loosened.

## Stability

- **Concurrency 502s and event-loop blocking**: large file reads/writes, archive extraction, directory cleanup and hashing now run asynchronously in slices or streams, with deduplication and single-flight on hot paths; when UI polling hits a transient 502 it keeps what is already rendered and retries with backoff instead of clearing progress.
- **No more permission-confirmation errors with background tasks**: orphaned background tasks after `--resume`, or tasks finishing right at the end of a turn, no longer close stdin early and produce "AbortError: Stream closed"; injecting into an idle turn is no longer cut off by the close timer.
- **Host lifecycle**: fixed the gateway stop → immediate-restart race, 127.0.0.2 loopback probing, and lock/resource handling in Shizuku, the installer and the updater; stripped-down ROMs without the relevant settings pages no longer crash.
- **Install and uninstall**: progress no longer shows `[object Promise]` / NaN; a failed first install rolls back to "not installed" instead of staying "damaged"; large package listings are parsed after stdout is drained.
- **Session rewind**: deleting, bulk-deleting, moving a session or removing a project directory is blocked while a rewind is writing.
- **openai-bridge**: switching to a new toolkit no longer leaves a reinstall deadlock or a permanent "local bridge disabled" false alarm.

## Security

- Sharing and archiving now block case variants of credential paths (e.g. /sdcard/.SSH/ID_RSA); archives exclude symlinks that escape the root or point into private/credential areas; `/data/data/<pkg>` and `/data/user/0/<pkg>` bind-mount aliases are recognized.
- Editing an MCP server now does remove + add atomically under a single lock, so concurrent edits no longer overwrite each other.

## Notes

- Full test suite passes (1950 gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
