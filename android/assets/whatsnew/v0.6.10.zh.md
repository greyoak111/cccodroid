这一版修完了 chenshi723 对 0.6.9 的整份审计（#180–#200）和一份私下报告的安全问题，又接着加固了两轮破甲检查，一共一百多处修复。

## 安全

- 判断「是不是应用私有目录」改按目录本身认，换个写法、软链、上级目录都绕不过去；项目、文件面板、Git、预览、Office 各处入口统一走这一道。
- 发行版封口补齐：项目说明里的 `@` 引用不能出项目根；skill、子代理头里写的钩子在副本里去掉；项目的输出风格顶替不了内置和你自己的风格；发行版回填进来的 MCP 和权限规则也要你在卡片上确认。
- Git 只信任登记过的项目目录；守卫部署时只认核过的源码；写 shell 启动文件、`~/.cccodroid/bin` 之前先问。
- 破甲检查认得更多改形写法（同形字、词间加分隔、多种外壳、多国语言直球），并收录红队新交来的整族载荷短语；日常说法照旧放行。
- 安卓侧：内部动作口令改由系统密钥库派生、不再明文存；系统文件选择器选不了应用自己的内部文件；Docs 文件访问不交出 Claude Code 的设置文件；界面每次请求先核网关身份，端口被别的应用占了不会把输入发过去。
- 组件和工具包：组件索引防回滚、缓存按签名复核；`devkit.lock.json` 验签；卸载只删前缀内的路径；技能包条目数有上限。

## 修复

- 运行链路：网关被结束时带走正在跑的 Claude；权限确认 30 分钟没人答按拒绝停下；一条事件出错不再带走整个网关；Claude 退出后管道被占也能按时收尾。
- 中断与恢复：中断卡分清是 App 更新、网关被关掉或重启、还是被系统结束；被结束的轮次恢复后不再误报「历史被改」；还没起进程就被停的给「重发」不给「继续」。
- 厂商配置：坏文件留底不覆盖；换主机清掉旧 Key；切厂商时清掉自动起名的旧型号；配置写错的字段不再当真。
- 定时任务：被系统推迟 30 分钟以内的照常补跑，不再记成错过；跑完后后台服务自己退出；后台起不了时发通知请你打开应用。
- 工具包升级不再删掉你放在 `$PREFIX` 里的东西；组件升级中途失败自动回滚到旧版。
- 状态文件、项目说明、账本统一原子写，读坏了留底；会话删除、搜索、导入导出、书签、Git 面板、文件与 Office 预览、终端各修了一批。
- 上游接口报错时，提示里多一句该怎么办（上下文太长、Key 不对、余额不足、限流、服务端出错等）。
- 从别的应用分享文件进来，先问一句再收；从附件栏移除时删掉拷进来的那份。
- 用手机浏览器直接打开网关地址时，提示「请在 cccodroid 应用里打开」，不再显示网关离线；网页页签换成应用图标。

## 行为变化

- Git 只信任登记过的项目目录；工作区外、没登记的目录不再往上级读 `CLAUDE.md`；项目说明里的 `@` 引用不能出项目根。
- 特权免确认时长可以选，最长一周。
- 发行版改了 MCP 或权限规则，要在卡片上确认才生效；有没确认的改动时，定时任务先不运行。
- 换全局接口时，跟随全局的项目和定时任务里旧接口的模型名会被清掉。
- 指定的工作目录不在了，这一轮报错不跑，不再悄悄换到工作区。
- 「继续」那一轮要真答出来，中断卡才撤掉。
- 系统文件选择器里选本应用的内部文件会被忽略，工作区文件请用输入框的 `@` 引用。
- 网关重启后，第一个请求可能先失败一次，随即自动恢复。
- 升级前发出、还挂在通知栏里的旧通知，点了不再响应。
- 新装后第一次升级，只显示当前这一版的说明。
- 分屏时正看着对话，跑完或待确认不再发通知。
- 定时任务跑完后，后台通知约一分钟内消失。
- 手动装回旧版 APK 不再当成升级，会提示文件被改动过、已按安装包还原。
- 从本地文件或暂存包装比现在旧的工具包，先要你确认。
- 技能包里文件超过 4096 个的直接拒绝。
