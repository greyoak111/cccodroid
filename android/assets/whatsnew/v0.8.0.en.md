Overhauls update and notice check lifecycles, and comprehensively hardens targetSdk 36 execution, large-archive extraction and security boundaries, host upgrade synchronization, and queue concurrency.

## Update & Remote Notice Overhaul

- **Read-only status decoupled from network checks**: Returning to the foreground and opening the account menu now query read-only `upd_status` without triggering implicit network update checks; split `lastAutoCheck` with a 10-minute foreground throttle, guarded concurrent checks via `checkedOnce`, and released `noticeHold` immediately on overlay close so remote notices never stall.
- **Direct provider setup routing**: Tapping the welcome Setup Guide or hitting an unconfigured `503` now forwards sub-tab arguments directly to **Settings → Provider** after providers finish loading.

## targetSdk 36 Execution & Host Self-Healing

- **Native shim & launcher alignment**: Replaced `faccessat(X_OK)` (blocked on `app_data_file` under targetSdk 36 W^X SELinux) in `exec-shim.c` with alignment-safe `newfstatat` mode-bit checks, switched `pre/adb` to `[ -f ]`, deferred `unset LD_PRELOAD` in `bin/claude` until right before `exec`, and injected `TERMUX_EXEC__PROC_SELF_EXE` in `Env.proc()`.
- **Race-free upgrades & gateway reaping**: Added atomic `AppFiles.ensureSynced()` locking to eliminate false tamper alerts when `MainActivity` and `GatewayService` race during app upgrades; persisted `.gateway.pid` with `/proc/<pid>/stat` field-22 `starttime` verification to reap non-dumpable leftover gateways across restarts; stripped `CCAPP_TOKEN_FILE` from helper subprocesses.

## Archiver, Security Seals & Queue Lifecycle

- **Large-archive support & secret safety**: Existing extraction destinations (such as `/storage/emulated/0`) now stage inside the target folder, backed by a 1-second `ENOSPC` free-space watchdog, symlink/dangling-symlink destination rejection (`403`), cycle-safe directory-symlink secret scanning, and shutdown `7zz` cleanup; directory listing keeps a 60s timeout for `/api/arc/list`, while extraction and single-entry preview run without a hard listing timeout and restore the 256 MB listing cap for multi-hundred-thousand-entry archives.
- **Seal hardening & overlayfs compatibility**: Excluded `.mcp.json` / `.lsp.json` at any plugin depth and stripped manifest hooks, added `.claude/commands` hook scanning and `O_NOFOLLOW` + `dev/ino` verification, and exempted volatile overlayfs `ctimeNs` checks in managed bridge configs.
- **Lane-aware scheduling, spaced image refs & UI lifecycle**: Isolated new-session lanes against accidental mid-turn injection and aligned scheduled-task `busySlots` with `runnableQueueCount()` so queued follow-ups on an already-running session no longer block schedules for 30 minutes; added `@"/path/with space.png"` inline image parsing and deduplication, `goalStateOfAsync` fingerprint cache parity, per-file `usageImport` fault tolerance, and page/visibility polling cleanup.
