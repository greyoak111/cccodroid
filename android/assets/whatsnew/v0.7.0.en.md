This release is a full stop — and a promised reunion.

The farewell letter shipped with 0.6.20 ended with “Let us meet again at v0.7.0.” v0.7.0 is here. The changes are small: automatic chat titles now follow the interface language instead of always coming out in Chinese, and the old name in the title bar is now cccodroid. As the letter said, there will be no new stable releases for a while; reports and questions are still welcome on GitHub or in the community group.

## Interface language

- Every UI request now refreshes the interface language remembered by the gateway instead of leaving it at the Chinese default from process start. In English, Spanish and other interfaces, automatic titles, archive hints, error messages and background notifications all follow the most recent interface language (#211).
- The title prompt now names the target language (English / Spanish / Japanese …) instead of only passing a language code.
- The static fallback title shown before the page script runs is now “cccodroid” instead of “Claude CLI”; once a session is open it still shows the session name or “New chat”.

## Notes

- No new features in this release, only the fixes above; upgrading leaves existing sessions, settings and archives untouched.
- Thank you to everyone who used, reported, reviewed and helped fix cccodroid.
