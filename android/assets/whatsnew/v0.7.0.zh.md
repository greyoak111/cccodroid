这一版是一个句号，也是一次如约而至。

0.6.20 的告别信里说「就让我们在 v0.7.0 再见吧」，现在 v0.7.0 到了。改动不多：修好了非中文界面下自动起名仍然给中文题名的问题，也把顶栏里那个旧名字换成了 cccodroid。按信里说的，接下来一段时间不会有新的正式版本；遇到问题仍可以在 GitHub 或交流群反馈。

## 界面语言

- 每个界面请求都会刷新网关记住的界面语言，不再停在进程启动时的「中文」；英文、西班牙文等界面下，自动起名、建档提示、错误消息和后台通知都跟着最近的界面语言走（#211）。
- 起名提示词直接写明目标语言（English / Spanish / Japanese …），不再只给语言代码。
- 顶栏在页面脚本加载前显示的默认标题从「Claude CLI」改为「cccodroid」；进入会话后仍显示会话名或「新对话」。

## 说明

- 这一版没有新功能，只有上面几处修补；升级不会改动已有会话、设置和档案。
- 谢谢每一个使用、反馈、审查和一起修补过 cccodroid 的人。
