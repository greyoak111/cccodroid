This release overhauls restart recovery and the trash: interrupted turns, queued messages and scheduled handoffs survive a system kill more completely; trash entries being permanently deleted show their real state and cleanup retries; saving a custom provider clears its key whenever the receiving endpoint changes; plus small UI fixes.

## Recovery & trash

- **More complete restart recovery**: interrupted turns, queued messages and scheduled-task handoffs left over when the system killed the app are now kept and restored in full.
- **Trash shows the truth**: sessions that are still being permanently deleted (waiting for storage to recover) are labeled as such and no longer offer Restore; deleting them again no longer misreports "a session with the same ID already exists"; restore failure reasons are shown as readable messages.
- **Half-moved sessions from older versions**: sessions whose main record reached the trash while side files stayed in the project folder can now be restored instead of getting stuck.
- **Dismissing an interrupted turn fails honestly**: if storage can't be written, dismissing reports "couldn't save" instead of pretending success and bringing the card back after the next start.

## Security

- **Custom provider keys are checked against the endpoint**: when saving a custom provider, the old key is cleared as soon as the receiving endpoint (host, port or protocol) for chat or the model list changes, so it never leaks to the new endpoint.

## UI

- **HTML diff preview**: fixed opening the preview from the diff page after a save, and keeping in-flight SSE tail frames when finishing conversations after returning to the foreground.
- **Picked-color theme composer**: the plus and interject mini buttons are vertically centered again.

## Notes

- Full test suite passes (gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
