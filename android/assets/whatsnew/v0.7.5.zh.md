这一版给 MCP 服务器加上了**直接编辑**，并修掉远程 MCP 表单一个会让令牌静默丢失的坑（[#225](https://github.com/greyoak111/cccodroid/pull/225)）。两处都来自社区贡献者 wumingzhinu 的报告与实现，编辑功能另收编了 ta 独立实现的思路（[#226](https://github.com/greyoak111/cccodroid/pull/226)）。

## MCP 服务器可直接编辑

- 用户级条目（**包括停用中的**）点「编辑」，或**长按 / 双击**条目，直接进编辑：名字、类型（stdio / http / sse）、命令或网址都能改，不用再删了重加。
- 令牌不回显：现有请求头、环境变量只显示**名字**，留空 = 保留原值；要换就填新的（同名覆盖）；点掉 chip 上的 × 就从配置里删掉。
- 保存时后台自动「移除 + 重写」；写不进去会把旧配置**原样恢复**，恢复也失败会明说。改名撞已有名字（含停用名单里的）直接拦下。
- 编辑停用中的条目只改停用名单，启用时按新配置加回。

## 远程 MCP 令牌丢失修复

- 「添加 MCP 服务器」表单里把 `Authorization=Bearer …` 写成**等号**时，以前会静默塞进环境变量——远程 MCP 没有子进程，令牌根本没发出去，最后报一个离真相很远的 `Dynamic Client Registration rejected (HTTP 404)`。现在选 http / sse 时输入框提示切成 `Header: 值`，提交时检测到 `KEY=值` 直接拦下并给出正确写法；后端再挡一道（[#225](https://github.com/greyoak111/cccodroid/pull/225)）。
- 列表条目显示已配置的**请求头名字**（不显令牌值），令牌到底配没配上，一眼可见。
- **行为变化**：编辑时把类型切成 stdio，请求头不会被保存（Claude 对 stdio 条目不存请求头）——保存前会弹确认，列明哪些请求头会被丢掉。
