This release brings archive browsing into the viewer: tap a zip/7z in chat and browse, preview, and extract it right in the viewer, just like in the file manager. Spreadsheets reopen at their saved active sheet, Git panel diffs show renames, saved custom commands keep their YAML comments, and usage stats now store UTC quarter-hours, fixing local-date attribution on non-whole-hour timezones.

## Viewer

- **Archive browsing**: tapping a .zip / .7z in chat opens it in the viewer — browse directories, preview files inside (text / images / documents), extract all or single files, with password-archive support. Returning to the archive from a nested preview and password retry on extraction work like the file manager. Nested archives are no longer previewed recursively; they fall back to plain files.

## Spreadsheets

- **Active sheet remembered**: a spreadsheet opens at the sheet that was active when it was last saved, instead of always the first one.

## Git panel

- **Diffs keep rename provenance**: a renamed file's diff shows old → new instead of looking like a delete plus an unrelated create.
- **Merge commits expand along the first parent**: history and single-file diffs no longer mix the other side of a merge into the current branch's changes.

## Custom commands

- **YAML comments and types preserved**: saving a command no longer drops comments, and true / false / numbers are no longer rewritten as strings.

## Usage stats

- **Stored as UTC quarter-hours**: usage on non-whole-hour timezones (e.g. +05:45) is no longer attributed to the wrong local date; the combined view and the quarter-hour detail no longer double-count legacy backfill buckets.

## Notes

- Test suite runs in parallel pools: a full local run went from ~12 minutes to ~4 minutes, CI from ~8 minutes to ~3 minutes, with two test-isolation issues the pooling exposed fixed along the way.
- Full test suite passes (nearly 1,800 gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
