This release is mostly fixes. chenshi723 did a full review of v0.5.20 and filed 80-odd findings; all of them are handled here. It also fixes two problems reported in the group chat: background tasks getting stuck, and the gateway crashing on startup.

## Background tasks

- When a turn had finished and only a background task was left (for example an SSH tunnel kept open), new messages could sit in the queue forever, and the stop button said the turn "already ended". You can now send into such a turn directly. If its input has already been closed, "Send now" and Stop end the turn together with its background tasks, the queued message goes out right after, and the answer is not marked as interrupted.
- If messages were still queued when the app last exited, the gateway could crash on restart and lose them. Fixed.

## Switching sessions (#87–#90)

- Step groups and subagent cards you collapsed by hand stay that way when you switch away and back.
- Switching to a running session no longer flashes old content, and context usage no longer leaks between sessions.
- Late replies for subagent transcripts no longer point "jump to" at cards that are gone.

## Review fixes (#95–#110)

The main ones:

- **Runs and usage**: a follow-up turn (from an interjection or a background report) that exits abnormally is no longer reported as a success; API usage is recorded for every result; switching currency converts old spending at the exchange rate; a scheduled task's per-run cost limit is checked after every result and stops the run once exceeded.
- **Scheduled tasks**: "Wi-Fi only" now actually receives the Wi-Fi state, including when a VPN is on; changing the system time zone reschedules tasks in the new zone.
- **Sessions**: moving, forking, restoring or importing no longer leaves half-done state behind when it fails; exported sessions include their archive data (chapter titles, status, volumes).
- **Git**: selective commits no longer include files that weren't shown in the list; staged renames commit completely; discarding a staged new file no longer errors.
- **Files**: symlinked folders open in the file panel; file names ending in a space open correctly; late replies in the editor no longer touch the file you're on.
- **Components and modules**: a component's skill no longer overwrites your own skill of the same name; removing a devkit module checks whether components or pkg packages still need it; an interrupted pkg install picks up where it left off when rerun.
- **Android side**: notifications show failures correctly; the system reclaiming the page renderer no longer takes the whole app down; attachments picked while the screen was recreated are no longer lost; the memory manager stops right away when turned off and lists apps it couldn't stop; two USB devices asking for permission at once no longer interfere; 35 native error messages are now translated.
- The APK now ships Shizuku's MIT license notice.

## Other

- New UI language: Indonesian (machine-translated first draft; corrections welcome).
- The OpenAI API local bridge settings can store several models per key, each with its own context window (#86). This needs the next component release; update it under Components once it's out.

## Known issue

- On one Red Magic phone, reopening the app and starting a new session failed with `Failed to fetch` because the gateway was unreachable; restarting fixed it. The cause isn't known yet. If you hit it, please pack the diagnostic logs from Settings and send them to us.
