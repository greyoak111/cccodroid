This release trims the chat bottom bar: the provider name no longer occupies the bar, so long provider names can no longer force it onto multiple lines; the bar layout returns to its pre-v0.7.11 form; and tapping an APK in chat installs it directly again.

## Chat bottom bar

- **Provider name off the bar**: the model area shows only the model name and reasoning effort; to see which provider a session uses, open the model picker.
- **Back to the v0.7.9 layout**: font size, wrapping and spacing return to how they were before v0.7.11 (the single-line bar, narrow-screen degradation and 48px touch targets from v0.7.11 are reverted).
- **Reasoning effort kept**: the bar still shows the reasoning effort, and tapping the model name still opens the picker.

## Files

- **Tapping an APK installs it**: APK files (any capitalization) tapped in chat go straight to the install confirmation instead of opening the archive browser; zip and other archives still open in the browser, and the file page's "open archive" button is unchanged.

## Notes

- Full test suite passes (gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
