This release is mostly about lag. Switching back to a long-running chat, opening a long sub-agent run, previewing a sparse but wide spreadsheet, and typing in a file with tens of thousands of lines no longer freeze the app for seconds.

## Lag

- Switching back to a chat that has been running for a long time no longer forces a layout pass per event, and a sub-agent's steps no longer turn into hundreds of main-thread cards when the parent card isn't loaded.
- Jumping into history from a chapter or bookmark now loads a normal-sized page instead of swallowing a whole turn with thousands of items.
- A sub-agent's run now shows the most recent part (the last steps and the report are included), builds only the latest 50 steps at once, and no longer blocks the gateway while loading.
- For imported or older agent chats, the contact log now reads only the lines it needs and remembers the result instead of parsing everything each time.
- Spreadsheets with a few cells spread over a huge range draw at most about 20,000 cells first; tap "Show more" to continue.
- When editing a file with tens of thousands of lines, line numbers are re-measured only for changed lines and drawn only for the visible part, so pausing while typing no longer stutters.

## OpenAI bridge

- The "Model name" suggestions on the config page now sit right below the field instead of floating semi-transparently over the page and keyboard.
- Bridges stuck after updating the component from r9 to r10 ("can't configure, can't uninstall") are fixed in component r11. After updating the component, start a new chat or save once on the config page and the old bridge upgrades itself.

## Other

- When a provider doesn't report a context window and no compaction threshold is set, the top bar still shows how much context is used ("capacity unknown"), and switching models no longer reuses the previous model's capacity.
- If the first install can't fetch the Claude Code version, it now says whether DNS, certificates, a timeout or something else was the cause. Diagnostic bundles now include failed self-checks and a network probe.
