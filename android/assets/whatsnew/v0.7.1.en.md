This release fixes one input problem: after the built-in browser pane is closed or hidden, tapping an input in the main UI could leave it without a cursor or keyboard.

## Input focus

- Opening the browser pane takes focus. Closing the pane, or hiding it because a settings page, large image or bottom sheet covers it, removed that focus; the main WebView did not take it back, so tapping an input gave no cursor and no keyboard.
- Closing or hiding the pane now returns focus to the main WebView when the pane had it; regaining window focus or tapping the main UI also restores it.
- While the pane is open and you are typing in its address bar or page, the main UI does not steal the keyboard.

## Notes

- No other changes; existing sessions, settings and archives are untouched.
- Thanks to the user who reported it with reproduction steps.
