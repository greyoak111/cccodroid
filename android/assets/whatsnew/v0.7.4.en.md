This release merges five pull requests from community contributor zhiererer (who found and pinpointed six of the seven issues fixed in 0.7.2), plus three fixes: chat text selection overflowing message boundaries, an occasionally blank Bridge settings page, and inconsistent context-window sizing. One **visible behavior change** comes first.

## Behavior change: external/headless sessions go to "Misc"

- Headless sessions started externally — skill subsessions, `claude -p` runs — no longer appear in the sidebar's "Recent" list; they are filed under **Misc** instead ([#218](https://github.com/greyoak111/cccodroid/pull/218)). You can still open them any time from Misc, and no history is affected.

## Three bridge hardening fixes

- **Preheat at startup**: the managed bridge used to be preheated only when you opened the Bridge settings page. It now preheats as soon as the app starts, so the first conversation doesn't wait ([#220](https://github.com/greyoak111/cccodroid/pull/220)).
- **Path aliases resolved by directory identity everywhere**: 0.7.2 only fixed uninstall detection; startup and repair now also identify directories by their real identity (device number + inode), so switching between `/data/data` and `/data/user/0` paths no longer breaks ([#219](https://github.com/greyoak111/cccodroid/pull/219)).
- **Stale fault lock recovery**: if the bridge gets stuck on a fault state left over from a previous cycle during startup or repair, it now unwinds and retries on its own — no manual cleanup ([#220](https://github.com/greyoak111/cccodroid/pull/220)).
- The openai-bridge component ships **r21**: the OpenAI-compatible endpoint now routes bare model names through MODEL_ROUTES — a model name that declares a unique upstream works directly, while unknown names still return 404 ([#217](https://github.com/greyoak111/cccodroid/issues/217)). Takes effect after updating the component.

## Clearer tamper alerts

- When runtime protection trips, the message now distinguishes the source — **file modified** vs **binary replaced** — and shows the detection time ([#221](https://github.com/greyoak111/cccodroid/pull/221)).

## New-conversation focus and accessibility

- On a fresh conversation the input box sometimes had no cursor and the keyboard wouldn't appear; focus is now restored right after entering a new chat ([#223](https://github.com/greyoak111/cccodroid/pull/223)).
- Accessibility confirm dialogs are no longer silently swallowed by the 20-second window, so screen-reader users can confirm normally ([#223](https://github.com/greyoak111/cccodroid/pull/223)).

## Chat text selection

- Selection no longer crosses message boundaries: "Select all" picks only the current message, and dragging into other messages, timestamps, or buttons snaps back — copied text no longer mixes in neighboring messages.

## Blank Bridge settings page

- In some cases the Bridge settings page opened blank. It now reopens itself to recover, and the loading overlay is hidden while closing. Diagnostic logging was added to the page; if you hit it again, the logs will tell us why.

## Consistent context-window sizing

- The bridge's context-window input now uses binary sizing — **1k = 1024** — matching what's displayed, instead of one place counting 1000 and another 1024 ([#222](https://github.com/greyoak111/cccodroid/issues/222)).

## Notes

- All five PRs passed the full test suite (1612 passing); the selection and blank-page fixes were made locally.
- Upgrading does not touch existing sessions, settings, or archives.
- Thanks to zhiererer: six of the seven issues fixed in 0.7.2 were found and pinpointed by them, and this release's five PRs and two investigation reports are theirs too — each with on-device verification and tests.
