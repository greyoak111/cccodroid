This release fixes one small problem.

## Fixes

- **Settings didn't update after switching the execution mode.** If you changed the execution mode in Settings to Auto, Direct or Via loader and let the gateway restart, the "Currently: …" line underneath kept showing the old mode until you restarted the app. Settings read the state once before the old gateway had exited, and never read it again after the new one came up. It now waits for the new gateway and then refreshes, so the new mode shows as soon as the restart finishes.
