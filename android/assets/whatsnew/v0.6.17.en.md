This is a stability release: more than seventy fixes from two stability reports, mostly for problems that only show up when the network drops, the system kills the app, or two things happen at once. The component market also gets a batch of new components.

## New components

14 new components under Extensions → Components. None has been verified on a device yet, so read the description before installing:

- Dev: android-build (build Android projects with Gradle), apk-tools (apktool + dex2jar), code-quality (shellcheck, shfmt, ruff), data-tools (CSV / XML), databases (a local Valkey key-value store)
- Science & AI: pandas, math-min (calculator, number theory, units, plots), ml-tflite (TensorFlow Lite inference), speech (speech to text and text to speech; models downloaded on demand)
- Media: skia-video (draw frames and compose videos), photo-min (photo metadata, filters, tracing, barcodes)
- Other: backup (restic encrypted backups), minecraft-server (Paper server), qq-bot (a QQ bot; unofficial, and the account may be restricted — see the disclaimer in the component description)

## Sending and drafts

- If the gateway stops responding, sending now fails after 20 seconds and your text goes back into the input box instead of spinning forever.
- Your message is saved before the input box is cleared, so a refresh, switching away or the system killing the app no longer loses it.
- When the gateway did receive a message but its reply got lost, you're told there's no need to resend; resending the same message only runs once.
- Pressing Enter while the keyboard is still composing no longer sends; pasting mixed text and images no longer drops text.

## Chats and history

- One broken record no longer stops the whole history from loading.
- If an answer is cut off (the app was killed, the gateway restarted), the history ends with a note that the last turn didn't finish; if tools that change files or run commands were involved, you're reminded to check before continuing.
- Tool cards that never got a result show "status unknown" instead of looking successful.
- When a third-party endpoint disconnects without an end marker, the answer is kept but marked as possibly incomplete.
- A permission prompt that times out now shows "timed out" instead of being recorded as your refusal.

## Settings and endpoints

- Switching a preset provider to another region without entering a new key now clears the old key, so it isn't sent to the new address.
- Testing an endpoint tells "invalid key" (401) apart from "access denied" (403, usually a region or network restriction).
- If an endpoint test or balance check echoes your key in its error, the key is removed before it's shown.
- Changing settings quickly, or right after opening the settings page, no longer gets overwritten by older data.

## Files, terminal and more

- Word / Excel files are checked by size first instead of being read fully into memory; Office previews stop as soon as they go over budget.
- Audio and video that can't be played show an explanation and a Share option.
- Truncated terminal output is marked; opening a terminal for a folder from Files opens that folder.
- Stopping a turn now also cleans up processes that turn started in the background; long-running services you asked Claude to start (such as openai-bridge) are left alone.
- When notifications are turned off in the system, the app says so instead of claiming it sent one.
- When the gateway is unreachable the app shows "gateway offline" and reconnects on its own.
- Logs include dates and no longer record the text of your prompts.
