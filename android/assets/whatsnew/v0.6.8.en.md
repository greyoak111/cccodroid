This release keeps hardening the jailbreak check, fixes models on third-party endpoints never compacting on their own, and merges a large batch of UI fixes found by the community.

## Security

- The jailbreak check recognizes more disguised forms: split characters, inserted punctuation, and text wrapped in several layers of encoding are restored before checking.
- Text injected into the conversation by hooks, and config files inside a project, now go through the jailbreak check too. If a hook's injection matches, that turn stops and the injected text is shown folded.
- The app now ships an anti-jailbreak rule set that Claude Code reads every turn, contributed by a red-team researcher.
- The config check now verifies the whole config. Extra environment variables in a provider's config can no longer be used to inject certificates or login tokens.
- A batch of fixes from the 11-05 security review: files are confirmed to be regular files before reading, credentials aren't read through symlinks, failed downloads no longer loop, and more.
- A batch of robustness fixes in the gateway and UI: scheduled tasks queuing twice or never running across midnight, errors that could crash the gateway, short writes being truncated, and more.

## Improvements

- Models on third-party endpoints (such as DeepSeek) without a compaction line set now auto-compact at 80% of the window by default. Before, they never compacted, and once the context hit the window limit even a manual `/compact` couldn't be sent.
- Custom providers can list extra models: in the provider card's "More models" field, write one per line, optionally followed by a space and the window (such as `256k` or `1m`).
- Code blocks of two lines or more show line numbers on the left; copying leaves them out (discussion #170).
- Tables in the Markdown editor are laid out as you type and render as a table once the cursor leaves.
- The sidebar has a "New conversations without a session" entry, so drafts that never got a session can be found again (#172).
- The session list has "Show 150 more" at the bottom for older sessions.
- The task list can be closed with ✕ at any time.
- Phone control: after a tap or swipe it waits for the screen to settle and brings back the new screen. Before acting, it checks that the numbered element is still the one it saw, so it won't tap the wrong thing after a list scrolls.
- Bash cards are titled with the model's description. When a provider error triggers a retry, the status code and reason appear in small text from the first retry.

## Fixes

- An unanswered confirmation card no longer holds the turn forever: after 10 minutes it lets go, and a turn that never got a session can be picked up again on the new conversation page (#171).
- Stale entries left after a session goes to the trash (scheduled task results, interrupted-run recovery, usage and so on) are all handled (#173, #178).
- Replies that arrive after you switch sessions only apply to the session that sent them (#174).
- Waiting confirmations are no longer hidden behind a full-page prompt, plan card buttons follow the mode, and answers you've typed are still there when you come back (#175).
- Bulk delete, export and misc cleanup only act on sessions you can see (#176).
- Late replies no longer land in the wrong panel, file or repo after you switch, and failed saves no longer show as saved (#177).
- Switching back to a long-running turn no longer re-syncs the layout repeatedly and stutters (#179).
- If the provider a turn needs has been deleted, the turn no longer quietly falls back to the global default.
- When the gateway restarts, it no longer kills background tasks that still belong to a running gateway.
- Everyday wording is no longer blocked by the jailbreak check, such as telling it not to worry about an error, skipping a system dialog while installing, or talking about iOS jailbreaking.
