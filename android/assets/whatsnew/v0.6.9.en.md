Hotfix: on some phones the gateway wouldn't start after updating to 0.6.8 and the app stayed on "Waiting for gateway…".

## Fixes

- On some phones the app directory path goes through a system link. The load check added in 0.6.8 then treated the gateway's own code as "outside the install directory" and refused it, so the gateway kept exiting right after starting. Both forms of the path are now accepted, and every module is still checked against the install package's file list.
- When the gateway keeps exiting, the notification now shows why it exited instead of only "Gateway exited; restarting in 8s", so a screenshot is enough to pin it down.

If you're still stuck on "Waiting for gateway": with auto-update on, this version will show up in a notification within a few hours; tap it to confirm the install. If you can't wait, download the APK from the GitHub Release or the website and install it over the current one. Your data isn't affected either way.

Thanks to chenshi723 for capturing the exit code and logs on an affected phone, which narrowed the problem down right away.
