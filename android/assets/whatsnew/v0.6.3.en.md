This release fixes several security issues, stops screen reading from reading password fields, and fixes a batch of problems found in the v0.6.2 review.

## Security

- Fixed several security issues.
- "Confirm sensitive actions" no longer has an off switch and is always on. Its description stays in Settings, and you still allow or deny each action on its card.
- "Pause all hooks" on the Extensions page now sets the rules aside and puts them back unchanged when you resume, so it no longer turns off "Confirm sensitive actions" as well. Hooks you had already paused are moved to the new method automatically after updating, and no rules are lost.
- `claude` run directly in the in-app terminal now also gets "Confirm sensitive actions".
- In safe mode, "Allow everything", "Decide automatically" and "Auto-accept edits" fall back to "Ask each time": hooks don't run in safe mode, so sensitive actions can't be caught on their own.
- Before each turn, the Claude Code program is checked against Anthropic's signed official manifest. If it doesn't match, it isn't started, and you're asked to reinstall it under Settings → Updates. The signed manifest is saved automatically the first time you're online after updating.
- When app files have been modified, they're still restored from the app package, and now the app also tells you once. Claude is also told on its next turn that the change was undone.
- Screen reading no longer reads what's in password fields. The field is still listed and marked as a password field, and Claude can still fill it in when you ask, but can't append to what's already there.

## Fixes

- If the disk fills up or a write fails while saving a file, the original is no longer wiped: the new content goes to a temporary file first and only replaces the original once it's fully written.
- When settings can't be written to disk, you're now told plainly that the change may apply for this run but will revert on restart, instead of it looking saved.
- A full disk during a segmented download no longer takes the whole gateway down; the download just fails.
- Output style files with no space after `name:` had the first letter of the name cut off. Fixed.
- Scheduled tasks:
  - the repeated hour when daylight saving time ends no longer hangs the gateway;
  - the daily limit is checked again right before a run starts, so a task that waited in the queue is skipped if the limit ran out meanwhile;
  - the daily limit no longer goes wrong once the run log gets long;
  - "Test run" uses a fresh session and doesn't affect the session the real runs continue.
- If usage stats are cleared while a backfill is running, the backfill's stale results are discarded instead of being written back.
- Cancelling a message in the middle of a queue no longer stops the later ones from continuing the original session.
- After you switch provider, model or thinking effort, messages are no longer sent to an idle background process still using the old settings.
- If the provider or model is changed elsewhere while `/model`, `/effort` and similar commands are fetching the model list, the command is dropped and you're asked to run it again, rather than writing the old settings back.
- Tool results and failure states no longer go missing when you scroll back through history.
- Numbers of deleted custom providers are never reused for new ones. If deleting a provider fails to save, it's rolled back instead of being half-deleted.
- When two components install a command with the same name at the same time, the second is blocked instead of overwriting the first.
- Checking for updates no longer crashes on Android 8.0 / 8.1.
- Tapping the update notification when the app isn't running now lets you continue the install; the package name and signature are checked again first.
- After a reboot, scheduled task alarms are restored even if Shizuku isn't running yet.
- The first-use confirmation for screen reading and tapping now waits up to 70 seconds, the same as the clipboard.
- Turning the work island off and on quickly no longer leaves two copies.
- A title you set by hand while a backfill is waiting is no longer overwritten.
