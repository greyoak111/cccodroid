This release fixes several security issues.

## Security

- Fixed several security issues.
- "Confirm sensitive actions" no longer has an off switch and is always on. Its description stays in Settings, and you still allow or deny each action on its card.
- "Pause all hooks" on the Extensions page now sets the rules aside and puts them back unchanged when you resume, so it no longer turns off "Confirm sensitive actions" as well. Hooks you had already paused are moved to the new method automatically after updating, and no rules are lost.
- `claude` run directly in the in-app terminal now also gets "Confirm sensitive actions".
- In safe mode, "Allow everything", "Decide automatically" and "Auto-accept edits" fall back to "Ask each time": hooks don't run in safe mode, so sensitive actions can't be caught on their own.
- Before each turn, the Claude Code program is checked against Anthropic's signed official manifest. If it doesn't match, it isn't started, and you're asked to reinstall it under Settings → Updates. The signed manifest is saved automatically the first time you're online after updating.
- When app files have been modified, they're still restored from the app package, and now the app also tells you once. Claude is also told on its next turn that the change was undone.
