This release is mostly about security: the programs behind Claude Code and the gateway are checked before they run, and Claude Code's config is checked before it's handed over. It also merges a batch of community fixes.

## Security

- Claude Code only runs if it matches Anthropic's signed manifest. Newly installed versions save the manifest automatically. Older installs without one fetch it first and don't run until they have it.
- The gateway checks the bytes of each file as it loads its own code, so swapping a file after the check doesn't work.
- The gateway now uses its own copy of its runtime (Node, the libraries it needs, and the glibc it starts Claude Code with), kept outside the toolkit and checked against the app package before every start. Package upgrades and toolkit updates don't touch it. The first start copies it from the toolkit, which **takes about 105 MB more space**; if the toolkit's version doesn't match, it's downloaded instead (about 130 MB).
- The app's own helper programs now live inside the app package, and other processes can't debug the gateway or Claude Code or read their memory.
- Claude Code's config (CLAUDE.md, rules, skills, commands, agents, output styles, plugins, MCP servers and auto memory) is scanned for jailbreak patterns before the gateway passes it to Claude Code. If something matches, that turn doesn't run and you're told which file and line. `claude` in the terminal goes through the same checks. Plugin hooks don't run, and skills are invoked as `/user:name`.
- Writing jailbreak content into CLAUDE.md, `.claude/` or the memory folder is blocked by the safety check.
- Usage queries only accept the exact host name.
- See "The code the gateway and Claude Code run" in SECURITY.md for details.

## Fixes

- Saving a file resolves the path before checking the target, so tricks like `/.` don't get around it, and it won't write to something that isn't a regular file.
- A Git project's trust record now covers hook contents, the full config and the gitdir; changing them asks again.
- Components check that a file is a regular file before reading anything you can edit.
- A broken entry in the ledger no longer crashes the gateway.
- Segmented downloads keep writing until every byte is on disk, instead of reporting success after a partial write.
- When the upstream connection is reset, the stream fix still reaches the UI.
- Concurrent sessions no longer collide on temporary thumbnail files.
- "Skip next run" on a scheduled task skips only that run.
- After a config change, ⚡ Send now ends an idle turn instead of getting stuck.
- Forked sessions with the same start time are ordered by creation time.
- App files that couldn't be read at startup are restored too.
- Opening another conversation while a turn is running no longer gets stuck on the config confirmation.
- Fixed several hangs and pointless waits: "Save to", failed silent installs, the update loop, and "Rewind and ask again".
