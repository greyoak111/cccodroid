这一版主要治卡顿：长任务会话切回来、长子代理的过程、稀疏的大表格、上万行的文件，打开或打字时不再一卡好几秒。

## 卡顿

- 切回一个跑了很久的会话时，不再逐条强制排版；子代理的步骤在父卡没加载时，也不再变成主流程里的成百上千张卡。
- 按章节、书签跳着读历史时，一页最多读到正常分量，不会一口吞下整轮几千条。
- 子代理的「过程」改成给最近的部分（最后几步和汇报都在），一次只建最近 50 步，读取也不再卡住网关。
- 导入的旧代理会话打开联络簿时，只读需要的行，读过的会记住，不再每次全量解析。
- 表格只有零星几格、跨度却很大时，先画两万格以内，余下的点「再显示」接着画。
- 编辑上万行的文件时，行号只重算改过的行、只画看得见的那段，停打不再卡一下。

## OpenAI 桥

- 配置页「模型名称」的下拉列表改成排在输入框下面，不再半透明地盖住页面和键盘。
- 组件 r9 升级到 r10 后「配不了、卸不掉」的问题已在组件 r11 修好：更新组件后开个新会话，或在配置页点一次保存，旧的桥就会自动升级。

## 其他

- 接口不报上下文窗口、也没设压缩线时，顶栏照样显示已用量（「容量未知」），换型号也不再沿用上一个型号的容量。
- 首装取不到 Claude Code 版本号时，会说清是域名解析、证书、超时还是别的原因；诊断包里多了自检失败项和网络探测。
