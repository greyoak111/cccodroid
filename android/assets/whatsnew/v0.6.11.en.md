This release adds the archive support that should have shipped with 0.6.10, and fixes several issues reported after 0.6.10 went out.

## New

- The file manager now handles archives: open one and browse it folder by folder without extracting; preview a single file inside it; extract next to the archive or to a folder you choose; or select several files and compress them to zip / 7z / tar.
- Supports zip (including jar and apk), 7z, rar (including multi-volume), tar and tar.gz / xz / zst / bz2, and single .gz / .xz files. Chinese file names in zips made on Windows are detected as GBK automatically. Encrypted archives open with a password, which is never stored.
- 7-Zip 26.06 ships inside the app; nothing extra to install.
- New "Reset settings" under Settings → Troubleshooting: when a broken configuration makes every turn get refused or produce no answer and you can't fix it yourself, one tap returns Claude Code's user-level configuration (CLAUDE.md, skills, plugins, hooks, MCP, memory), cccodroid settings and shell startup files to a fresh install. Everything is moved to `~/.ccapp-reset` as a backup, not deleted; conversations, the workspace and the toolkit stay, and keys are kept by default. If the gateway won't start, it's also on the startup screen under "I'm stuck" and on the waiting page.

## Fixes

- The context usage bar no longer gets pushed under the top bar when you scroll (the whole page no longer scrolls).
- The system prompt is no longer passed on Claude Code's command line: running `ps` in a session used to show the whole system prompt, and the model would mistake it for injected text.
- When the gateway has to download its own runtime again, the startup screen now shows download progress, speed and time left, and says an interrupted download resumes; it no longer switches to a page that can't load while this is going on.
- You can now extract an archive directly into the workspace itself.

Thanks to everyone in the group who reported problems right after 0.6.10, with screenshots and diagnostic bundles.
