这一版给 MCP 服务器表单加了防坑提示，同步了两个 QQ 机器人组件的重要变化（NapCat 官方删库后的多源回退、新增 SnowLuma 组件），使用说明也补了一轮。

## MCP 表单防坑提示

- 添加 / 编辑 MCP 服务器时，类型选 http / sse，网址框下会显示提示：服务器就在本机就填 `http://127.0.0.1:端口` 最稳；局域网 IP 会随网络切换而变，导致 MCP 断连。
- 检测到 `192.168.` / `10.` / `172.16-31.` 开头的地址时，提示换成橙色警示（只提醒、不拦截——服务器在别的机器上时局域网地址才是对的）。
- 起因：群里一位用户排查 MCP 老是断连，最后发现是配置走了局域网 IP、IP 一跳就断。感谢「炔剑」的排查。

## 组件市场

- **QQ 机器人（原生 NapCat）**：NapCat 官方仓库 2026-11-12 删库（Release 与 License 地址全部失效），安装器改为按序回退到两个公共档案镜像，所有源共用同一个 SHA256 校验，任何一个源内容不符都会拒绝；官方源哪天恢复自动用回。已经装好的不受影响。
- **新增 SnowLuma 组件**：原生 Linux QQ + SnowLuma 2.4.2，OneBot v11 + 白名单桥，与 QQ 机器人（NapCat）同款机制。SnowLuma 官方同样已停止公开（律师函），组件走三个公共档案镜像多源下载。
- 两个组件的官方源码历史、tags 与 Release 产物均已抢救存档并逐哈希验证，官方删库不影响新装。

## 使用说明

- 「多种接入方式」补上 OpenAI 协议路径：只给 `/v1/chat/completions` 的服务 → 可选组件装「OpenAI API 本地协议桥」→ 点「配置」；内置帮助此前已有完整说明，这次把 README 对齐。
- 组件数量、MCP 直接编辑（长按 / 双击进编辑、令牌只回显名字）等表述同步更新。
