这一版把压缩包浏览搬进了查看器：聊天里点开 zip / 7z，和文件管理器一样在查看器里翻目录、预览、解压；表格重新打开会回到上次的活动工作表，Git 面板的单文件对比能看见改名来源，常用指令保存不再丢 YAML 注释，用量统计按 UTC 刻钟存储修正了非整点时区的本地日期归属。

## 查看器

- **压缩包浏览**：聊天里点开 .zip / .7z 等压缩包，直接在查看器里浏览目录、预览包内文件（文本 / 图片 / 文档）、解压全部或单个文件，支持密码包；从包内预览返回压缩包、解压时密码重试等操作与文件管理器同款。包里的压缩包不再递归预览，按普通文件兜底。

## 表格

- **活动工作表记忆**：表格打开时回到上次保存时所在的工作表，不再总是第一张。

## Git 面板

- **单文件对比保留改名来源**：同一文件改名的对比显示 old → new，不再当成删了旧文件新建新文件。
- **合并提交按第一父展开**：历史与单文件对比不再把 merge 的另一边混进当前分支的改动里。

## 常用指令

- **保留 YAML 注释与原始类型**：保存指令时注释不丢，true / false / 数字不再被改写成字符串。

## 用量统计

- **按 UTC 刻钟存储**：非整点时区（如 +05:45）的用量不再算到错误的本地日期；合并视图与刻钟明细都不会把旧式补算桶重复计数。
