这一版修了几处安全问题，读屏不再读取密码框的内容，另外修了一批 v0.6.2 审查里发现的问题。

## 安全

- 修了几处安全问题。
- 「敏感操作再确认」不再提供关闭开关，一直开着。设置里还保留它的说明，碰到时照旧逐次在卡片上允许或拒绝。
- 扩展页的「暂停全部 hooks」改成把规则先挪到一边保存，恢复时原样挪回，不再连带关掉「敏感操作再确认」。以前已经暂停的，升级后自动按新办法保存，规则不会丢。
- 应用内终端里直接运行的 `claude` 也会挂上「敏感操作再确认」。
- 开着安全模式时，「全部放行」「自动判断」「自动接受编辑」这几档会退回「逐项确认」：安全模式下钩子不运行，敏感操作没法单独拦下。
- 每轮启动前会按 Anthropic 签名的官方清单核对 Claude Code 程序，对不上就不启动，并提示到「设置 → 更新」里重装。升级后第一次联网时会自动补存签名清单。
- 应用文件被改过时，除了照旧按安装包还原，界面也会提示一次；下一轮还会告诉 Claude 改动已撤销。
- 读屏时不再读取密码框里的内容：框照样列出、标明是密码框，Claude 仍可以按你的要求填写，但不能在原有内容后面追加。

## 修复

- 保存文件时如果磁盘写满或写入出错，原文件不再被清空：先写到临时文件，成功后才替换。
- 设置没能写进磁盘时，界面会明确提示「这次运行内可能生效，重启后回到旧值」，不再假装保存成功。
- 分段下载时磁盘写满，不再让整个网关退出，改为报下载失败。
- 输出风格文件里 `name:` 后面没有空格时，名称会被吃掉第一个字母，已修正。
- 定时任务：
  - 夏令时回拨那一小时不再让网关卡住；
  - 每日额度在真正开跑前再核一次，排队期间额度用完就跳过；
  - 运行日志多了以后，每日额度也不会再算错；
  - 「试跑」用新会话，不影响正式运行续接的会话。
- 统计补算期间清空了统计，补算的旧结果会被丢弃，不再写回来。
- 排队的消息撤销中间一条后，后面的仍然接着原会话发。
- 换了接口、型号或思考强度后，不再把消息塞进还在后台、用旧设置的进程里。
- `/model`、`/effort` 等型号清单的时候在别处改了接口或型号，这次命令作废并提示重新执行，不会把旧设置写回去。
- 往上翻历史记录时，工具调用的结果和失败状态不再丢失。
- 删掉的自定义接口编号不会被新接口复用；删除接口时写盘失败，会还原，不会出现删了一半的情况。
- 两个组件同时安装同名命令时，后装的会被挡住，不再互相覆盖。
- Android 8.0 / 8.1 上检查更新不再崩溃。
- 点更新通知冷启动应用时，可以接着安装，安装前会再核一次包名和签名。
- 重启手机后，即使 Shizuku 还没启动，定时任务的闹钟也会恢复。
- 第一次用读屏、点按时，确认框的等待时间放宽到 70 秒，和剪贴板一致。
- 工作岛快速关了又开，不再出现两份。
- 补档等待期间你手动改的标题，不会再被覆盖。
