## 安全

- 修了几处安全问题。
- 「敏感操作再确认」不再提供关闭开关，一直开着。设置里还保留它的说明，碰到时照旧逐次在卡片上允许或拒绝。
- 扩展页的「暂停全部 hooks」改成把规则先挪到一边保存，恢复时原样挪回，不再连带关掉「敏感操作再确认」。以前已经暂停的，升级后自动按新办法保存，规则不会丢。
- 应用内终端里直接运行的 `claude` 也会挂上「敏感操作再确认」。
- 开着安全模式时，「全部放行」「自动判断」「自动接受编辑」这几档会退回「逐项确认」：安全模式下钩子不运行，敏感操作没法单独拦下。
- 每轮启动前会按 Anthropic 签名的官方清单核对 Claude Code 程序，对不上就不启动，并提示到「设置 → 更新」里重装。升级后第一次联网时会自动补存签名清单。
- 应用文件被改过时，除了照旧按安装包还原，界面也会提示一次；下一轮还会告诉 Claude 改动已撤销。
- 读屏时不再读取密码框里的内容：框照样列出、标明是密码框，Claude 仍可以按你的要求填写，但不能在原有内容后面追加。
