Two small improvements in this release: install packages straight from your files, and selecting text no longer drags the top bar into the selection.

## New

- `.apk` files now have an "Install" button, both on the viewer's "no built-in preview" page and in the file page's preview bar. Tapping it first shows cccodroid's own confirmation with the app name, package name and version; only after you allow it is the system installer opened. Requests are refused while cccodroid is not in the foreground, so nothing can keep popping install prompts in the background. New versions of cccodroid itself are still installed from Settings → Update.

## Fixes

- When you drag-select text in the chat past the top or bottom of the chat area, the top bar badge, the context usage bar and the model / permission status line at the bottom are no longer pulled into the selection, and copied text no longer starts with these interface labels (#201).
