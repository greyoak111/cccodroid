这一版的重点是会话不再被悄悄删掉，并新增存储页，管理本应用占用的空间；另外有几处好用度和稳定性的改进。

## 会话永久保留

- Claude Code 默认会把 30 天没动过的会话连同附属数据一起删掉，不进回收站，网关里的会话也在其中。现在改成永久保留：会话只有你在会话列表里删了才会进回收站。你自己在 `~/.claude/settings.json` 里写过 `cleanupPeriodDays` 的，按你写的天数。
- 项目目录里的设置文件也改不了这个保留期（以前克隆来的仓库写一句「保留 1 天」就能让会话被删光）。
- 从回收站彻底删除会话时，它在别处留下的附属数据（环境快照、任务清单、调试日志、后台命令的输出）一起删掉，不留残渣。

## 新功能

- 设置 → 存储：看本应用占了多少空间、设备还剩多少，按六类分开列出——缓存、临时文件、Claude Code 的杂物可以一键清理；会话、程序和你的文件只显示大小；回收站、旧工具包残留、卸掉的组件留下的数据、用量统计汇总在一处，点一下回到原来的地方处理。
- 自动清理：默认每周一次（可选每天、每月，也可以关），只清缓存、7 天没动过的临时文件和 30 天前的 Claude Code 杂物；正在用的、会话正在跑的不碰。会话、你的文件、程序永远不会被自动删除。
- 扩展页的技能、MCP 服务器、组件、工具包模块都可以「停用」了：先不用，不必卸载，随时启用回来。

## 改进

- 发出消息后、Claude 第一次回应前，「连接中」拆成三段显示：准备中 → 启动中，连接工具 → 连接中，每段带用时，慢在哪一步一眼能看出来。
- 文件页的压缩入口更好找：长按文件出「重命名 / 压缩…」，单个文件的预览栏也有「压缩…」。
- 导入技能包时在后台线程里解压，大的技能包解压期间界面和别的请求不再卡住。
- 底部确认条上的「允许」：单张敏感操作卡会带着风险说明，只放行条上显示的那一张。

## 修复

- 整页在长按拖动、输入框聚焦等情况下不再被整个滚走（上一版修过一部分，这次补全）。
- 同一个会话号在两个项目目录里都有记录时，按这一轮的工作目录取 Claude Code 实际会读的那一份。
