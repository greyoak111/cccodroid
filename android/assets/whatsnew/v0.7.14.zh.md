这一版修掉启动与更新两个老毛病，并补齐文件、Git 与定时任务的一批边界问题：应用内更新不再误报「读不到签名」、启动页不再被残留代理拖在「等待网关」；工具包新增 Rust、Python 现代工具与 Autotools 模块，登录 shell 默认跟随系统时区。

## 启动与更新

- **应用内更新修复**：部分 Android 13–16 机型上只带 v1+v2 签名的安装包读不到签名、更新被拒——现在逐级回退取签名证书，不再误报（known-issues #10）。
- **启动页不再长停「等待网关」**：连本机网关的请求一律不走系统代理（设备配过 HTTP 代理或残留失效代理时，发往 127.0.0.2 的请求会被拖去反复超时，known-issues #8 高概率根因）。
- **空闲停机更稳**：网关停机收尾期间用户回到界面，服务不再被误停；连接也会及时释放。

## 文件与 Git

- **/sdcard 大小写防呆**：凭据文件名和目录（.ssh、id_rsa 等）的大小写变体同样被拦下，不再绕过保护。
- **重命名与删除同口径**：目录软链、悬空软链可以改名自身；只改大小写的重命名照常放行。
- **Git 联网超时整组清理**：超时后 pre-push 钩子与 ssh 子进程不再残留，不与用户的重试撞在一起。
- **压缩包自包含检查**：/sdcard 别名路径下不再绕过「压缩包不能放进正在压缩的文件夹」的检查。

## 定时任务与界面

- **条件检查一律 fail-closed**：Wi-Fi、充电、电量条件判断不了时跳过执行，不再误触发。
- **stdio MCP 参数**：编辑保存时含空格、引号的参数不再被切碎。
- **滚动冻结提示**：冷却提示改为「长按顶栏标题约 0.6 秒脱困」。

## 工具包

- **新增可选模块**：Rust 语言（含 rust-analyzer）、Python 现代工具（uv / ruff）、Autotools 与 Perl——到 扩展 → 工具包模块 按需安装，不占整包体积。
- **C/C++ 构建与命令行增强补工具**：bison、flex、gperf、libtool、ccache；tmux、git-lfs、fontconfig 工具。
- **登录 shell 默认时区**：跟随系统时区，不再默认 GMT；Python 的 zoneinfo 时区库离线可用（内置 tzdata）。
