这一版修好扩展页 GitHub CLI 登录卡在「正在向 GitHub 申请一次性码…」的问题，并修复安卓上看门狗心跳失效、登录时弹出多余确认框等一批问题。

## GitHub 登录

- **一次性码识别**：gh 复制到剪贴板后输出的是「One-time code (XXXX-XXXX) copied to clipboard」，旧正则只认「one-time code: XXXX-XXXX」，界面因此一直停在「正在申请一次性码…」。现在两种格式都认，并去掉 ANSI 颜色码。
- **不再弹剪贴板确认框**：登录子进程的 PATH 剔除 app/pre（termux-clipboard-set / xdg-open），并挂上只回传网址的 xdg-open / termux-open-url 垫片，gh 不会在后台偷偷写剪贴板、弹出「允许写入剪贴板？」。

## 稳定性

- **安装心跳恢复**：安卓 SELinux 不允许应用读 /proc/uptime，看门狗心跳退回墙钟后被 Java 当成未来时间，组件 / 模块安装的宽限期一直不生效。现在先回退到 os.uptime()（与 SystemClock.elapsedRealtime 同基准），再退墙钟。
- **终端桥加固**：cli-bridge 增加 socket 超时、响应大小上限、stdin 20 万字符上限与空闲超时，支持 `--` 分隔符，避免卡死和超大输入。
- 本版也包含 v0.7.17 的启动修复（部分机型卡在「等待网关…」）。
