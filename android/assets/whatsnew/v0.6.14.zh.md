这一版把「OpenAI API 本地协议桥」扩展的配置页升级成可以管理多个 API。

## 新功能

- 扩展页里本地协议桥的「配置」现在可以添加多个 API：每个 API 分别填地址、替换 Key、选模型和上下文窗口，再从所有模型里选一个默认项；多个 API 共用同一个本地桥，保存后统一生效。不同 API 里同名的模型会保留各自的别名，不会互相覆盖。移除 API 前会先确认，当前会话保持不变。Key 只在保存时交给组件，配置页不读回、不回显。要用多 API，需要把扩展里的本地协议桥更新到 r19；旧版组件仍走原来的单 API 表单，并提示更新（#202，由 chenshi723 贡献）。
