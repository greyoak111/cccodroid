这一版把工作岛直接内置进应用（Android 16+ 系统实况通知，低版本可用悬浮胶囊兜底），大于 512 MB 的文件也能零拷贝分享，项目记忆可以在应用内只读查看；同时集中修掉并发 502、事件循环阻塞、后台任务权限确认「Stream closed」和一批安全与稳定性问题。

## 工作岛（内置）

- **不再依赖外部伴侣应用**：工作状态直接显示在系统灵动岛 / 实况通知。Android 16+ 使用系统原生 Live Updates，自动适配荣耀灵动胶囊、ColorOS 流体云、小米超级岛等；低版本或系统未放行的机型可开启触摸穿透的悬浮胶囊兜底；都不满足时用同卡进度通知。
- **设置页可自检**：实时显示通知与悬浮窗权限状态，一键跳到系统设置，支持 10 秒试播；切回前台自动刷新。
- 任务完成 8 秒后自动收起，点击直达对应会话；支持计时与 TodoWrite 分段进度。

## 大文件分享

- **解除 512 MB 限制**：分享工作区或 /sdcard 文件改为零拷贝只读句柄，毫秒级弹出系统分享面板，不再复制整份文件、不占额外空间；授权 24 小时内有效，应用重启后也不影响网盘慢速上传。
- 安全边界不降级：凭据、私有目录、硬链接照旧拦截；授权后原路径被替换成软链会拒绝读取。

## 项目记忆

- 项目详情「记忆 → 查看」改为应用内只读查看器：列出记忆文件、渲染 Markdown，可复制全文；没有编辑、删除入口，也不加载本地或网络图片。
- 通用文件接口对私有记忆目录仍然返回 403，防线没有放宽。

## 稳定性

- **并发 502 与事件循环阻塞**：大文件读写、压缩解压、目录清理、哈希校验改为异步分片 / 流式，热路径去重与单飞；前端轮询遇到瞬时 502 保留已渲染内容并退避重试，不再清空进度。
- **后台任务权限确认不再报错**：--resume 孤儿后台任务或本轮末尾任务清零时，不再提前关闭 stdin 导致「AbortError: Stream closed」；空闲轮次插话也不会被收尾定时器掐断。
- **宿主生命周期**：修复网关停机→秒重拉竞态、127.0.0.2 回环探测、Shizuku / 安装器 / 更新器的锁与资源释放；精简 ROM 缺系统设置页时不再崩溃。
- **安装与卸载**：进度不再显示 [object Promise] / NaN；首次安装回滚后状态回到未安装，而不是永久「损坏」；大包文件清单等 stdout 排空后再解析。
- **会话回退**：回退写盘期间禁止删除、批量删除、搬移会话或删除项目目录。
- **openai-bridge**：切换新工具包后不再出现重装死锁或永久「本地桥已停用」误报。

## 安全

- 分享与打包统一拦截大小写变体凭据路径（如 /sdcard/.SSH/ID_RSA）；压缩包排除指向私有区 / 凭据的软链与逃逸软链；识别 /data/data/<包名> 与 /data/user/0/<包名> 绑定挂载别名。
- MCP 编辑的先删后加改为单锁原子执行，避免并发编辑互相覆盖。
