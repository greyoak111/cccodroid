Fixes preference rollback when version pinning fails and syncs the current app version badge on startup, while temporarily taking down the in-app and website QQ group and Discord links.

## Update & Version Sync Fixes

- **Pin-failure rollback & symlink target check**: If pinning a specific Claude Code version fails in Settings → Updates, the previous channel and pin preferences are rolled back automatically; version checks now verify that the `current` symlink target binary actually exists on disk so dangling symlinks are never misreported as installed.
- **Immediate app version forwarding**: Gateway status and capability payloads now forward `appVersion` from the native shell so the Current Version badge in Release Notes renders immediately without waiting for an update check.

## Community Links & CI Hardening

- **Temporary takedown of QQ group & Discord links**: Temporarily removes the QQ group number (and QR code) and Discord server invite from the in-app menu, Help footer, What's New dialog, website, and repository docs, to be restored at a later date; GitHub Discussions and Issues remain open as usual.
- **Cross-platform CI & host test fixes**: Fixes `x86_64` runner compatibility in architecture-specific unit tests and Java test tool discovery, and adds failure log excerpts across test pools.

## Notes

- Gateway/frontend test suites, Java host tests, and all 9 language dictionaries pass verification.
- Upgrading does not touch existing sessions, settings, or archives.
