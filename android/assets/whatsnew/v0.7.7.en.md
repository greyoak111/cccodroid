This release fixes two component-install reliability issues (automatic mirror retry when the package source signature check fails, and the component record cap raised from 1 MB to 8 MB), and the glibc-side GPU driver in the market is now Mesa 26.2.7, bringing GPU support to Adreno 8xx devices.

## Component install

- **Automatic mirror retry on signature failure**: when the Termux repo's Release signature verification fails, the installer now retries with the next mirror. During the source's publish window, the Cloudflare mirror could briefly serve a stale signature, which occasionally made a component fail to install or update.
- **Component record cap 1 MB → 8 MB**: components with very many files (e.g. melt's shared-file list) are no longer misjudged as damaged; doc symlinks of glibc components are exempted, so the install audit no longer wrongly reports "shared files deleted".

## Component market

- **gpu-driver-glibc updated to 26.2.7 (Mesa Turnip)**: glibc-side Vulkan now works on Adreno 8xx (840 / 830 etc. — 24.2 didn't recognize these GPUs and reported incompatibility), and OpenCL via clvk-glibc works on top of it.
- **openscad export fixed**: after the toolchain's boost moved to 1.92, scad-export crashed on launch; r3 ships a compatibility shim and STL export works again.
- **libreoffice ICU added**: PDF conversion used to fail with a missing libicuuc.so.79; r3 bundles the dependency and Office → PDF works again.
