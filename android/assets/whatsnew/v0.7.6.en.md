This release adds a safety hint to the MCP server form, ships two important QQ bot component changes (multi-source fallback after NapCat's repo was deleted, and a new SnowLuma component), and brings the docs up to date.

## MCP form hint

- When adding or editing an MCP server with transport http / sse, a hint appears under the address field: if the server runs on this device, use `http://127.0.0.1:port` — a LAN IP changes when the network switches and the connection drops.
- Addresses starting with `192.168.` / `10.` / `172.16-31.` turn the hint into an orange warning (a reminder only, never a block — a LAN address is correct when the server runs on another machine).
- Origin: a community member tracked down why their MCP kept disconnecting and found the config used a LAN IP that kept changing. Thanks to 炔剑 for the investigation.

## Component market

- **QQ bot (native NapCat)**: NapCat's official repo was wiped on 2026-11-12 (releases and license URLs all dead). The installer now falls back through two public archive mirrors in order, with the same SHA256 check on every source — any file that doesn't match is rejected. If the official source ever comes back, it is used again. Existing installs are unaffected.
- **New SnowLuma component**: native Linux QQ + SnowLuma 2.4.2, OneBot v11 plus the allow-list bridge, same architecture as the NapCat QQ bot. SnowLuma also stopped being public (legal notice), so the component downloads from three public archive mirrors.
- The official source history, tags and release artifacts of both projects have been rescued and hash-verified; the takedowns don't affect new installs.

## Docs

- "Ways to connect" now covers the OpenAI protocol path: services that only offer `/v1/chat/completions` → Optional components → install the "OpenAI API local protocol bridge" → tap Config. The in-app help already had the full walkthrough; the README now matches it.
- Component counts and direct MCP editing (long-press / double-tap to edit, tokens never echoed) are reflected.

## Notes

- Full test suite passes.
- Upgrading does not touch existing sessions, settings, or archives.
