This release fixes a handful of interface problems, and context usage finally shows up for third-party providers.

## Fixed

- **Context stayed at 0 with third-party providers**: bridges such as claude-code-router only report real usage at the end of a response, and we only read the placeholder 0 at the start. Usage is now picked up at the start, at the end and from the full message, and reopening an old session no longer reads it as 0.
- **The greeting flickered on a new chat with interface motion off**: the screen was cleared, then redrawn once the connection came back, leaving a blank moment. It's now drawn right away and kept when the connection returns.
- **Two kinds of sidebar on wide screens**: after collapsing the sidebar, the menu button brought it back docked on the left, but swiping in from the edge opened the phone-style drawer over the chat. On wide screens it now always comes back docked.

## Improved

- **No animation when switching settings categories on wide screens**: pick a category on the left and the content on the right just changes.
- **Interface errors show where they happened**: the top bar only fits one line, so error messages got cut off. The file and line number now come first, so a screenshot is enough to find it.
