Fixes an infinite startup retry loop when a pre-downloaded toolchain becomes older than a newly upgraded APK's built-in pin, and unblocks native confirmation dialogs during startup and local toolchain installation.

## Startup & Toolchain Update Fixes

- **Discard stale staged toolchains & unblock newer online updates**: When an APK upgrade raises the built-in `devkitPin` above a previously staged toolchain download, `Updater` initialization and unattended startup now discard the stale staged record and clean up cached files immediately, while `checkDevkit` allows newer online releases to replace older staged plans instead of getting stuck on `Installing downloaded toolchain update...`.
- **Eliminate `booted == false` confirmation dialog deadlocks**: `MainActivity` now handles privilege confirmation, folder consent, and accessibility confirmation intents immediately even while `booted == false` (cold boot, local archive install, and update-card install), eliminating the 60-second circular wait; unattended boot staging runs non-interactively and falls through cleanly to the main UI whenever an existing toolchain is intact.
- **Accurate downgrade baseline for repair & manual installs**: Same-version repairs bypass downgrade prompts, and manual local installs compare against the actual installed toolchain version when known rather than falsely flagging upgrades below a newer built-in pin.
