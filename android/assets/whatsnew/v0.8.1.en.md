Hardens privacy and outbound network controls, Accessibility guardrails for sensitive apps, and open-source compliance tooling, while adding live background task observability and concise UI copy across the app.

## Privacy, Outbound Controls & Accessibility Guardrails

- **Default-off proxy & decoupled update switches**: The third-party GitHub download proxy (`gh-proxy.com`) now defaults to **OFF** across the native installer, updater, and gateway (`files/.gh-proxy` as the single source of truth, cleared on factory reset); added a standalone **Maintenance Notices** toggle decoupled from signed `claude-verified.json` known-bad update holds (which now follow **Automatic Updates**, with the 20s startup check also gated when auto-update is off).
- **High-sensitivity foreground blocking in Accessibility**: The Accessibility channel now hard-blocks screen reading, screenshots, and gesture/input actions whenever the active foreground window belongs to banking, payment/wallet, 2FA authenticator, password manager, or system `permissioncontroller` packages.
- **Source-linked privacy docs & compliance tooling**: Added bilingual `PRIVACY.md` and source-symbol-linked privacy sections in `README`, plus package license extraction in `devkit` and the `archive-sources.mjs` Corresponding Source verification/archiving tool.

## Live Background Task Observability & Concise Copy

- **Background task & daemon lifecycle**: Added live metadata tracking, `runStrip` progress, and background phase indicators for running shells and subagents, closing cross-turn `sub_done` routing, stopped-task settlement, and daemon card state updates.
- **Concise UI copy & 9-language sync**: Rewrote verbose UI, gateway, and native Android strings into direct, concise phrasing while preserving all safety, recovery-lock, and factory-reset disclosures; synced all 9 language dictionaries (3,164 Web entries and 611 Android entries) and hardened backend `L()` and non-Han static key scanning.
