This release fixes the permission-confirmation race during background idle (no more popup errors or missed cards), polishes a batch of UI issues in the shise skin and segmented controls, and adds the Haskell toolkit module; large-module installs and toolkit updates are more robust.

## Permission confirmations

- **Idle race fixed**: permission requests (archiving, questions, …) that arrive while the idle close timer is counting down no longer get their input channel closed early with "Stream closed"; after stdin is closed, no unanswerable ghost permission cards are created.
- **Missed cards self-heal**: pending confirmation cards missed due to reconnect/resume or view rebuild are now re-painted from the gateway's authoritative state — the UI no longer waits out a 30-minute timeout.
- **Stopping tasks no longer hurts the next round**: with several background tasks running, if some are stopped and the last one finishes on its own, the 6-second short close no longer cuts off a fresh round on large contexts.

## UI

- **Shise input centered**: the single-line input text no longer sits below the buttons on non-landing pages; input height is recalculated when switching skins or font size.
- **Model dialog scrolls**: the effort and provider segmented bars scroll horizontally when there are many providers or long names, instead of being clipped (shise skin included).
- **Scheduled-task dialog**: long segments ("what if another chat is running", "validity") now scroll; the "run history" row no longer overflows on narrow screens.
- **Settings segments wrap without clipping**: multi-line wrapped segmented controls no longer have their corner text cut off by the rounded border.

## Toolkit & installation

- **New Haskell module**: GHC 9.12 + cabal (~2.8 GB installed), on demand under Extensions → Toolkit modules; packaging is now streaming and no longer limited by memory.
- **Large-module installs are safer**: installing or removing modules with thousands of files now yields the event loop in batches and writes heartbeat files, so the system watchdog won't kill them; archive scans are cancellable.
- **Toolkit updates save bandwidth**: when the toolkit hasn't reached the pinned version, the base module archive fetched for the gateway is kept and reused by the following update (saves ~123 MB).
- **php module composer fixed**: signed phars are no longer byte-rewritten into "signature mismatch" — kept intact with a wrapper script (absolute-path invocation).
- **Shared runtime names disambiguated**: shared libraries now display by content (clang / guile / libllvm / openjdk-21); shared layers still depended on by components or pkg packages are kept when removing a module.

## Notes

- Full test suite passes (1906 gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
