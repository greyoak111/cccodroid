This release fixes two long-standing startup/update problems and closes a batch of edge cases in files, Git and scheduled tasks: in-app updates no longer misreport "can't read signature", the splash screen no longer hangs on "waiting for gateway" behind a stale proxy; the toolkit gains Rust, modern Python tools and Autotools modules, and login shells follow the system time zone.

## Startup & updates

- **In-app update fixed**: on some Android 13–16 ROMs, packages signed only with v1+v2 returned no signature and the update was refused — the signer is now resolved with step-by-step fallbacks, so the false "can't read signature" is gone (known-issues #10).
- **Splash screen no longer stalls on "waiting for gateway"**: requests to the local gateway always bypass the system proxy (a configured HTTP proxy or a stale failed proxy used to drag requests to 127.0.0.2 into repeated timeouts; likely root cause of known-issues #8).
- **Idle shutdown race fixed**: if the user returns to the UI while the gateway is finishing its shutdown, the service is no longer wrongly stopped, and connections are released promptly.

## Files & Git

- **Case-insensitive /sdcard protection**: mixed-case variants of credential names and directories (.ssh, id_rsa, etc.) are now blocked just like the originals.
- **Rename matches delete**: directory symlinks and dangling symlinks can be renamed themselves; case-only renames keep working.
- **Git network timeout kills the whole group**: pre-push hooks and ssh children no longer leak after a timeout, so they can't collide with the user's retry.
- **Archive self-containment check**: /sdcard alias paths can no longer bypass the "archive must not be placed inside the folder being compressed" check.

## Scheduled tasks & UI

- **Conditions fail closed**: when Wi-Fi, charging or battery state can't be determined, the task is skipped instead of firing anyway.
- **stdio MCP arguments**: arguments containing spaces or quotes are no longer mangled when editing and saving.
- **Scroll-freeze hint**: the cooldown tip now says "long-press the top bar title for about 0.6 s to escape".

## Toolkit

- **New optional modules**: Rust (with rust-analyzer), modern Python tools (uv / ruff), and Autotools & Perl — install on demand under Extensions → Toolkit modules, without growing the full package.
- **More build and CLI tools**: bison, flex, gperf, libtool, ccache; tmux, git-lfs, fontconfig tools.
- **Login shells follow the system time zone** instead of defaulting to GMT, and Python's zoneinfo works offline (bundled tzdata).

## Notes

- Full test suite passes (gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
