This release fixes three issues reported in the group chat and on GitHub.

## Permissions and plans

- With "Allow everything" on, if Claude entered plan mode by itself, approving the plan lowered your permission mode to "Ask each time" or "Auto-accept edits". The plan card now has "Approve, keep current mode", which returns just this run to the mode it was in and leaves your global setting alone.
- Answering a permission request can no longer widen the mode. To widen it, switch in Settings, which asks first.

## Steps and images

- A step group with an image in the middle couldn't be collapsed. Now it can.
- When an image path in command output can't be read (for example `/data/adb`, which only root can read, or a file that doesn't exist), the preview no longer leaves a dead path behind, and the step group is no longer held open by it.

## Components

- The local OpenAI API bridge (openai-bridge) is updated to r14. Some upstreams reject the reasoning-effort parameters with a bare `400 Invalid request payload`, which failed the whole turn. The bridge now resends once without those two parameters, and remembers that for later requests (#84). Update it under Components.
