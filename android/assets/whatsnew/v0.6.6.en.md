This release tightens several checks in app updates, so upgrading no longer triggers a false "tampering" notice, and fixes a batch of issues found in reviews.

## Updates

- After a new version is installed in the background, the UI and gateway files are laid down again from the new package instead of being treated as "program files modified": no tampering notice, and Claude is not told that someone changed the program. If the files change while the version stays the same, they are still restored and you are still warned.
- A new package must come with a sha256 checksum or it won't be downloaded, and it is checked against that value again right before installing, so a package swapped after download is not installed.
- Besides matching the installed app's signature, the package must also be signed with the cccodroid release certificate.
- Silent installs stop the gateway first; the new version starts it again.

## Fixes

- After tapping "Stop" in the ongoing notification, the UI no longer gets stuck on a page that can't connect. Long-pressing the title to reload now shows "Waiting for gateway", starts the gateway and opens the UI once it's up; if the UI stays disconnected while open, the gateway is started automatically too. This means that tapping "Stop" while the UI is open brings the gateway back within a few seconds; to stop it for good, close the UI first, then tap Stop.
- After jumping to an earlier point from a chapter or bookmark and deleting a message, scrolling down no longer skips unread content.
- Switching to another session right after "Rewind and ask again" no longer overwrites that session's draft with the rewound prompt.
- In a step group you collapsed by hand, tapping an agent on the subagent contact card now expands it and scrolls to it.
- Git: if you write a commit message in another repository while a commit is still running, finishing the first commit no longer clears it.
- Merge: changing a selection while materials are being fetched now uses the new selection instead of putting old material under the new label.
- "View in Lineage": when the target is hidden by a project filter or by "hide misc", the filter that hides it is lifted.
- Reference links: newly opened sessions and newly added chapters are no longer reported as "not found".
- Hooks: if a rule changes or is deleted while you're editing it, your edit is no longer saved onto a different rule; "Pause" now applies to the level you're viewing, so project hooks can be paused too.
- Undoing a config change restores extension files exactly as they were, byte for byte and with their permissions.
- A skill ZIP import that fails halfway no longer leaves an empty folder holding the name.
- Cancelled downloads and previews no longer leave files open; very long file names can be saved and uploaded; pushing a branch whose name starts with HEAD is no longer refused.
- Deleting a scheduled task while it runs still records that run's cost; interrupted runs without a session ID are no longer cleared along with others.
- Moving a session now finishes writes the system only partly completed instead of leaving a truncated file; the self-test summary is shown in full; CPU usage of nested child processes is no longer counted twice.
