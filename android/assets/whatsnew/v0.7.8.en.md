This release fixes stuck installs after the gateway is killed mid-install (most visible with multi-thousand-file components like the GPU driver), stops the context usage bar from swinging back and forth on compatible endpoints, lands the frontend fluency fixes from the audit, and adds a local PDF toolbox to the viewer.

## Component install

- **Automatic recovery from interrupted installs**: when the gateway is killed while installing a large component (memory pressure, swiping the app away), restart now picks up where it left off — restoring the old version, completing what had finished, or offering a clean reinstall — instead of being stuck at "installing". Moves yield periodically, and the watchdog uses the install heartbeat to widen its timeout, so slow storage no longer looks like a hang.
- **Recovery no longer deletes the wrong files**: three wrong-deletion fixes (commit-point judgment, deletion set, pre-backup window). Concurrent recoveries and overlapping gateway instances no longer delete each other's files or the other's live install heartbeat. Recoveries now converge to the true state instead of a fake "installed".

## Chat

- **Context usage bar no longer swings back**: endpoints like Qwen report a smaller input usage at the start of a request; it is now held until that request confirms it, so the top usage bar no longer drops and climbs back (which looked like repeated compaction). Real drops after compaction or tool cleanup still show immediately.

## Frontend fluency

- **Chat hot path**: bounded code highlighting, on-demand tool-group windows, unified frame scheduling for animations — long replies no longer stutter.
- **Heavy previews**: Excel parsing moved into a worker, lineage graph caching and viewport culling, fewer redundant re-renders in the session list and scheduled tasks.
- **Oversized Markdown degrades gracefully**: giant code blocks, long lists, and single-line monster files render in chunks instead of freezing the whole block.

## Viewer

- **Local PDF toolbox**: merge, split, rotate, extract pages; image conversion scales to page size. Everything is processed locally — files are never uploaded.

## Notes

- Full test suite passes (nearly 1,800 gateway tests plus Java stub tests).
- Upgrading does not touch existing sessions, settings, or archives.
