This release fixes 30-plus issues from two review reports, and tightens which privileged commands run without asking.

## Chats and messages

- When several chats are interrupted at once, each one now gets its own "Continue" card, and the chat list marks them as interrupted.
- Prompts that start with something like `<div>` no longer vanish from the history.
- Deleting a reply no longer removes the compaction summary along with it. If the prompt for a reply was already deleted, you get a clear hint instead of a cryptic error.
- If you switch chats while an attachment is uploading, it lands back in the draft of the chat it came from.
- The model you pick in a new chat is now remembered together with its provider.

## Files, Git and scheduled tasks

- The viewer recognizes UTF-16 and GBK files (read-only, so they can't be saved in the wrong encoding). UTF-8 files with a BOM keep it when saved.
- Discarding a symlink in Git removes only the link. File names with special characters are taken literally, and a timeout now ends the whole process group.
- A scheduled task that was deleted or turned off while queued no longer starts. One-off tasks waiting in the queue aren't closed as expired.
- Chat archives are checked for corruption on import; damaged ones aren't imported.
- Uninstalling an old component no longer deletes files that a newer toolkit has taken over.

## Privileged commands and device tools

- Commands run through Shizuku now ask first for: `dumpsys` without a service name, `logcat` (it can read logs from every app), and reading files in shared storage. The memory manager keeps working as before.
- Device tools now ask in cccodroid before writing to the clipboard or opening another app.
- Opening an HTML preview in the browser always asks first, whether or not network access is on.
