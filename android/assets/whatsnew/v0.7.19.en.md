This release adds a native execution trampoline for Go binaries under targetSdk 36, brings split-screen Shizuku pairing, optional wireless ADB keepalive, and in-place privileged approval renewal, and lands a broad batch of security, performance, bridge recovery, and 9-language localization fixes.

## Runtime & Shizuku experience

- **Native targetSdk 36 trampoline (`libccrun.so`)**: Under loader execution mode, Go and static binaries (`gh`, `go`, `rclone`, `hugo`, etc.) that issue raw `execve` syscalls no longer fail with `EACCES` under Android W^X restrictions, including multi-hop chains such as `gh → git`.
- **Shizuku split-screen pairing & wireless recovery**: Wireless debugging pairing can open Android Settings in split screen; an opt-in local wireless ADB keepalive restores Shizuku after Wi-Fi drops and cleanly reverts TCP/ADB state when turned off.
- **Privileged renewal & single verification per visit**: Expired fixed privileged-command approvals can be renewed directly from the confirmation prompt after system verification; visiting Device & Permissions reuses a single system credential check per visit.
- **Toolchain swap & prompt cache TTL**: Fixed read-only directory cleanup during toolchain reinstall/swap ("rename failed"), and added pass-through for 5-minute / 1-hour prompt cache TTL settings to main sessions and subagents.

## Security, stability & localization

- **Security & seal hardening**: Safety guard hooks now anchor to the verified bundled Node runtime; Claude Code binary verification binds same-handle SHA-256 with nanosecond `ctimeNs` and process mapping checks against double-swap TOCTOU tampering; URL launch entry points share strict scheme/authority/port validation; memory-directory collision tracking writes atomically without following symlinks.
- **Stability & local bridge self-recovery**: Reworked JSONL paging, token scanning, and incremental search indexing to chunked buffers with line-size caps, eliminating $O(N^2)$ copies on huge single lines; protected on-device `llama-server` model loading with handoff leases against concurrent session preemption; allowed managed OpenAI bridge configurations to quarantine and recover from corrupted mapping files.
- **Frame budget & 9-language completion**: Restored same-frame scroll coalescing during tool bursts, `requestAnimationFrame` composer auto-sizing, and reflow-free completion animations; fixed archive viewer breadcrumbs on special paths and preserved search/multi-select state on split-screen extraction; completed all 9 UI dictionaries (3,171 entries aligned).

## Notes

- Full test suite passes (1,976 gateway/frontend tests, Java stub tests, and native trampoline build checks).
- Upgrading does not touch existing sessions, settings, or archives.
