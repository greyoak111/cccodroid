This release upgrades the configuration page of the "OpenAI API local protocol bridge" extension so it can manage several APIs.

## New

- The local protocol bridge's "Configure" page in Extensions can now hold multiple APIs: each has its own address, replaceable key, models and context windows, and you pick one default model across all of them. All APIs share the same local bridge and take effect together when you save. Models with the same name on different APIs keep their own aliases instead of overwriting each other. Removing an API asks for confirmation first, and your current session stays unchanged. Keys are only handed to the component when you save; the page never reads them back or shows them. Multiple APIs need the bridge extension updated to r19; older versions keep the single-API form and prompt you to update (#202, contributed by chenshi723).
