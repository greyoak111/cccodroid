The focus of this release is that conversations are no longer deleted behind your back, plus a new Storage page for managing the space the app uses. There are also several usability and stability improvements.

## Conversations are kept forever

- By default Claude Code deletes conversations untouched for 30 days, together with their attached data, without going through the trash — including the gateway's conversations. They are now kept forever: a conversation goes to the trash only when you delete it from the conversation list. If you set `cleanupPeriodDays` yourself in `~/.claude/settings.json`, your number of days is used.
- Settings files inside a project folder can no longer change this (previously a cloned repository could set "keep for 1 day" and wipe your conversations).
- Permanently deleting a conversation from the trash now also removes the data it left elsewhere (environment snapshots, task lists, debug logs, background command output).

## New

- Settings → Storage: see how much space the app uses and how much is left on the device, listed in six groups. Caches, temporary files and Claude Code housekeeping files can be cleaned with one tap; conversations, programs and your own files only show their size; the trash, leftovers from an old toolkit, data left by removed components and usage statistics are summarised in one place, with a tap taking you back to where each is managed.
- Auto-clean: weekly by default (daily or monthly, or off). It only removes caches, temporary files untouched for 7 days and Claude Code housekeeping files older than 30 days, and never touches anything in use or belonging to a running conversation. Conversations, your files and programs are never deleted automatically.
- Skills, MCP servers, components and toolkit modules on the Extensions page can now be disabled instead of uninstalled, and enabled again at any time.

## Improvements

- Between sending a message and Claude's first response, "Connecting" is now split into three stages — Preparing → Starting, connecting tools → Connecting — each with its own timer, so you can see which step is slow.
- The compress option in the file page is easier to find: long-press a file for "Rename / Compress…", and a single file's preview bar has "Compress…".
- Importing a skill package now unpacks it on a background thread, so large packages no longer freeze the interface or other requests.
- "Allow" on the bottom confirmation bar: a single sensitive-action card now carries its risk note, and only the card shown on the bar is allowed.

## Fixes

- The whole page no longer scrolls away on long-press drags or when an input gets focus (partly fixed in the previous release; now complete).
- When the same conversation ID has records in two project folders, the one Claude Code actually reads for the current working folder is used.
