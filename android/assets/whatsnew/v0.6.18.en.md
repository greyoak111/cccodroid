This release mostly fixes the UI and the gateway handover; the context compaction line for third-party endpoints also works again.

## Gateway and startup

- The app no longer falsely reports “port taken by another app” while the gateway is being replaced: when the old gateway has not exited and the new one does not yet have the startup nonce, a neutral waiting page is shown until the app has checked the process.
- If a real gateway comes up while residual gateways are being cleaned up, the app adopts it instead of starting another one that fights for the port.
- Heavy work such as component installs holding the gateway event loop for a moment is no longer treated as a dead gateway; it is restarted only after being unreachable for long enough.

## Third-party endpoints and context compaction

- When a custom endpoint does not report a context window, or even a model list, the compaction line no longer disappears: an unknown window shows a numeric input, using exactly what the model reports and never inventing a number.
- The compaction line now backfills correctly on the Claude Behavior page when the model list is empty or the current model is an alias.
- Values above 1M are reported and saved as 1M; if saving fails, the input and slider return to the value that is actually stored.

## Interface

- A batch of long-text overflow fixes: settings, permission cards, scheduled-task rows, chat and task titles, extra directories, the completion popup, the context usage bar, archive dialogs, chart tooltips and failure banners. Long paths, long translations and RTL layouts no longer push content off screen or get clipped.
- The Retry / I’m stuck buttons on the setup page are stacked and each takes a full row; the splash status may use two lines and expands the full setup page when tapped.
- Scheduled-task titles now have a minimum width; buttons wrap to a new row instead of squeezing the title into an ellipsis first.
- Resetting to initial settings now also clears the waiting-page state.

## Other

- New messages were translated into all eight languages.
- Ten more host regression tests cover gateway adoption and the UI page state.
