This is a small release: third-party endpoints now accept Chinese and bracketed model names, and the preset model lists cover every model still available through its Anthropic-compatible endpoint.

## Third-party endpoints

- Model names are no longer limited to English letters, digits and a few symbols: Chinese names and bracketed price tags used by third-party providers (for example “中转的中转:[特价C]claude-fable-5”) can now be saved and selected.
- Spaces, commas, line breaks, zero-width and bidi control characters are still rejected; the 128-character limit is unchanged.
- The related messages were translated into all eight languages, with regression tests added.

## Preset model lists

- The static lists for every preset endpoint now include all models still callable through that endpoint. Context windows and output limits are exactly what the vendor reports; unknown values stay empty.
- Anthropic sign-in now lists Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5, the older generations still online and the limited-availability Mythos models.
- GLM, Qwen, Volcengine Ark, StepFun, Qianfan, Tencent Hunyuan / TokenHub, LongCat, xAI and Meta were completed from their official lists; Kimi, MiniMax and DeepSeek keep the models on their official Anthropic whitelists.
- Older IDs that only work on the OpenAI / standard API were left out, so selecting them doesn't fail.
