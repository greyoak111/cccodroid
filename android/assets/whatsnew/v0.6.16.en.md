This release fills in a few long-standing gaps: you can delete things in Files, third-party endpoints list their models without a model-list URL, and custom endpoints no longer wait forever.

## New

- Delete in Files: long-press a file or folder and choose Delete, or select several and tap Delete (n) at the bottom. You're asked to confirm first; folders are deleted with everything in them. Private folders and key files can't be deleted.
- Model lists for third-party endpoints: when a custom endpoint has no model-list URL, opening the model panel tries /v1/models and /models on the endpoint's own host and lists what it finds, and remembers it for next time. Only the endpoint's own host and port are tried, so your key isn't sent anywhere else.
- A new MCP category under Extensions → Components: these components register themselves as MCP servers on install and are removed on uninstall. The first two are for Bilibili: bilibili-mcp (reads video info, subtitles, comments, search and favorites; read-only) and bili-groups (organizes your follow groups; changes your account).
- A new Help section, "Third-party endpoints": setting up an Anthropic-protocol custom endpoint, configuring several APIs in the OpenAI bridge, context windows, timeouts and common errors.

## Fixes

- Custom endpoints now have a request timeout by default. When an endpoint accepted a request but never sent anything back, the app used to sit at "Connecting" indefinitely; now the request is retried after 90 seconds without a response, up to 3 times. A timeout you set on the endpoint yourself still takes precedence (#203).
- The "三审 Pass1/Pass2/Pass3" line no longer appears at the end of answers. The checks still run in the background; nothing is added when they all pass.
