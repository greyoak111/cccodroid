This release fixes the problems that turned up once people started using the OpenAI bridge, and stops Xiaomi phones from locking the app at 60 Hz.

## OpenAI bridge

- Fixed the bridge failing to start on the newer package (the "36" build), with the config page reporting "Failed to read bridge configuration".
- When a provider doesn't publish a model list, the model you configured still shows up in the model picker, so any chat or new chat can switch to it. You no longer have to go back to Extensions and tap "Use in a new chat".
- Both the bridge config page and custom providers now have a "Context window" field. Once it's filled in, large-context models are no longer compacted early at 200k.
- If an older version or hand-copied files were left behind, reinstalling the component no longer ends in "installed, but reported as not installed".
- Tidied up the config page layout; the two buttons no longer touch. (Update the component to r10.)

## Context and compaction

- The "compact at" figure in the top bar now shows the value that actually applies. If it's set higher than the model's window, the window is used instead of a number that can never be reached.
- Compaction no longer prints several "Compacting context…" lines in a row. Each compaction gets one line, which turns into the result when it finishes.

## Other

- On Xiaomi / Redmi (HyperOS), the system treated the app as a game and locked it at 60 Hz. It now follows the system refresh rate setting. Thanks to HyotmakFin.
- Fixed an occasional red "interface script error" caused by key events that carry no key name.
