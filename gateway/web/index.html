后台与性能

后台运行
并行会话数

每多跑一个多占几百 MB 内存

不同会话可以同时干活，同一个会话里还是一条接一条。每多跑一个要多占几百 MB 内存，手机内存紧时调小；1 = 一次只跑一轮。

静态程序兼容

罩住 claude 拉起的所有程序

网上下载的静态程序（多是 Go 写的命令行工具和 MCP 服务器）会用到安卓禁止的新系统调用，直接被系统杀掉。开着它，这些调用会改成「不支持」，程序自己退回老办法接着跑。每次启动子程序多一点点开销；遇到怪问题可以关掉试试，下一条消息生效。

程序启动方式

自动：按安装包定。直接执行：工具包里的程序直接运行（targetSdk 28 的安装包）。经加载器：借系统加载器间接运行，targetSdk 36 的安装包只能这样；28 的也能选，用来排查问题。改完重启网关才生效。

内存管家

开启：允许停掉白名单以外的后台应用（需要 Shizuku）

不会被停的：你正在看的、分屏的、挂着前台通知的（代理、音乐）、桌面、输入法、无障碍服务、VPN、Shizuku，以及它们依赖的组件，再加上下面的白名单。 终端里用 cc-mem run -- 命令 跑重活：开跑前清场，跑的时候谁复活就再停谁。

安装包方案

targetSdk 28 是默认的那套，兼容性最好；targetSdk 36 给系统不让装 28 的新机器用。两套功能一样，数据通用，互相覆盖安装不丢东西。自动：跟着现在装的走，系统拒装 28 时自动换成 36。

自动更新

自动更新（默认开）：Claude Code 静默更新；新版应用下载好后提醒安装（有 Shizuku 时空闲自动装）；开发工具包只在 Wi‑Fi 下预先下载，下次打开应用时装上
