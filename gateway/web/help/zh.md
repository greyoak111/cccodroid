# cccodroid 使用帮助

cccodroid 在手机上跑**官方原版 Claude Code**，外面套一层图形界面，再配一整套开发工具。Claude 能读写文件、跑命令、开本机服务，和在电脑终端里一样。

## 快速上手

1. **装工具包**：第一次打开先勾要装的模块，默认约 330 MB，断了能续传。
2. **登录或填 Key**：Claude 账户在浏览器里授权一次就好；也能填 Anthropic、DeepSeek、通义等兼容接口的 Key。
3. **开一个对话**：顶栏的 ＋，或侧栏的「新对话」。
4. **让它干活**：改文件、跑命令前会先问你；输入栏下面能切权限模式。

## 界面一览

顶栏右边平时只有一个 ⋯，点一下，最常用的几个入口从它左边滑出来；再点一下（这时它变成 ›）收回去。下次打开应用还是上次的样子。

| 按钮 | 作用 |
|---|---|
| 📁 | 文件浏览器：看、改、预览工作区里的文件 |
| >_ | 终端：和 Claude 用的是同一套工具链 |
| 🌐 | 浏览器：本机服务和回复里的链接，平板上停在右边 |
| ‹› | 命令面板：斜杠命令、技能、常用操作 |
| ＋ | 新会话 |
| ⋯ | 展开 / 收起上面这几个键 |

左上角的菜单键打开侧栏：上面是去哪（对话、项目、定时任务，「更多」里是扩展、能力、用量、帮助），中间是最近的对话，最下面的账户行进设置。

顶栏下面的细线是**上下文用量**，越往右越满；后半截写着当前接口还剩多少：账户登录是 5 小时和每周额度已用的比例，DeepSeek、Kimi 等是余额。接口不报上下文窗口时，在设置「接口与型号」里给自定义接口填上「上下文窗口」，压缩线和刻度就按它算；没填时显示「容量未知」。点一下这条线弹出明细，所有接口的额度、消费和快用完时的提醒在「用量」页最上面的「额度与消费」。输入框左边的 ＋ 是附加文件和常用操作；下面一行是型号、思考强度和权限模式，点一下就能换。型号选单里只列能用的接口：没登录的官方账户、没下过模型的端侧不列；配好了但不想在这里看到的，在设置「接口与型号」里选中那一家，关掉「在模型选单里显示」（配置照留，正在用的那家总会列出来）。

## 按自己的习惯摆

- **外观**：设置 → 通用 → 外观，有原生、求索、逐月、构成、拾色五套，每套都分浅色和深色。「构成」是方角、粗墨线、牛皮纸底配红，适合喜欢硬朗一点的；「拾色」的整套颜色跟着手机壁纸走（Material You）。
- **强调色**：设置 → 通用 → 强调色，八个预设色或自己取色。同一个颜色会按当前外观的底色自动调深浅，浅色、深色下都看得清。
- **消息下面的按钮**：设置 → 通用，用不上的（比如书签、分叉）点一下藏起来，你的消息和 Claude 的回复分开设。
- **顶栏按钮**：设置 → 通用 → 顶栏按钮。每个按钮可以「常驻」（一直露在顶栏，不用先点 ⋯）、「收进 ⋯」或「隐藏」；按住左边的把手上下拖换顺序。点「恢复默认」回到原样。
- **字体**：界面和回复两处各自能换。设置 → 通用 → 导入的字体，选一个 ttf / otf / woff / woff2 文件导进来，再在对应那一项点「自选…」。字体里没有的字（比如英文字体里的中文）会用自带字体补上。代码和终端固定用自带的等宽字体。
- **常用指令**：常发的长提示存成一条指令，输入框里打 / 就能选，见下面「扩展」。
- **侧栏常驻项**：侧栏「更多」最下面的「自定常驻项…」。

这些选择存在应用自己的数据里，清 WebView 缓存也不会丢。

## 对话

- **回车发送**。生成中再发会排队；⚡ 是插话，递进正在跑的这一轮，不打断它。
- `/` 唤起斜杠命令，`@` 引用文件；在别的应用里「分享 → cccodroid」能直接变成附件。
- 输入框左边的 ＋ 上排四格：附加文件、拍照、截屏、浏览文件。拍的照片会缩到长边 2048 像素再附上。**长按「截屏」是 5 秒后截屏**：趁这几秒切到要截的应用，截完自动回来。
- 工具调用收成一行「3 个步骤 · 完成」，点开看每一步；要你确认的、失败的会自动展开。
- **子代理**单独一张卡，排在派它们的那组步骤下面：一个子代理一行，看得到状态、步数、正在干什么；点一行展开它的过程。底部是联络线「谁 → 谁 · 为什么事」。每个子代理的交代和汇报存在项目目录的 `.cccodroid/agents/` 里，点「交代」「汇报」就能看。
- 回复里的路径点一下就在查看器里打开，网页链接在应用内浏览器里开。
- 每条消息下面四个键。你的：复制、重发、回退到这里、删除。Claude 的：复制、转发、从这里分叉、删除。
- **回退到这里**会先列出之后改过的文件，再让你选只撤销代码，还是连对话一起回到这里。用命令改的文件不会还原。
- `/goal 完成条件` 让 Claude 一轮接一轮干到条件满足；后台任务和任务清单显示在输入框上方，可以单独停；后台任务多时收成一行，点一下展开。
- 网关重启、应用被系统收掉时正在跑的会话，列表里标「已中断」，打开后点「继续」接着跑，几个会话各有各的。
- **杂项**：试模型、打招呼这类零碎会话，Claude 建档时会顺手归进「杂项」，不占侧栏，在「对话」页最后一组。置顶的、正在跑或等你确认的照常留在侧栏。AI 归的杂项，会话一旦压缩过一次或超过 512 KB，就自动回到正常分组；你自己在菜单里「归入杂项」的不受影响，「移出杂项」随时可以拿回来。
- 侧栏「对话」页能搜内容、按条件筛、导出导入 zip；删掉的进回收站，保留 30 天。

## 权限与安全

| 模式 | 行为 |
|---|---|
| 问我（默认） | 读文件不问；改文件、跑命令、联网前先问 |
| 接受编辑 | 改文件不问，跑命令还要问 |
| 计划 | 只读、出计划，你批准了再动手 |
| 自动 | 由 Claude 的分类器判断哪些要问（实验） |
| 不问就拒 | 要确认的一律拒绝，适合没人看着的时候 |
| 全部放行 | 什么都不问，只在你信得过当前任务时用 |

**全部放行到底意味着什么。** Claude 不再问你，想改什么文件、跑什么命令都直接做，包括删东西、联网、往外发数据。风险主要不在 Claude 自己，而在它读到的东西：网页、下载的文件、别人的仓库、issue 里都可能藏着写给 AI 看的指令（提示注入），让它去读你的密钥、改配置、把东西传出去。逐项确认时你会看到这一步、能拒绝；全部放行时就没有这一关了。所以：

- 只在任务明确、你知道它要碰哪些文件的时候开，做完切回去。
- 让它读陌生网页、陌生仓库、来路不明的文件时，别开全部放行。
- 「敏感操作再确认」（设置 → Claude 行为，默认开）是兜底：Claude 要读密钥和登录凭据（.env、SSH 钥匙、接口密钥、网关令牌等）、读屏或替你点按别的应用、读剪贴板、把文件分享出去时，全部放行也会弹一张红边卡片问你。看到它而你并没让 Claude 这么做，就拒绝。它只认明面上的写法，故意绕开的认不出来，别把它当成全部放行的保险。

- 确认卡出现在对应的工具下面，输入框上方也有一条常驻提示。可以允许、始终允许或拒绝，拒绝时能附一句理由。批准权限请求不会顺带放宽模式，要放宽到设置里切。
- 开着「全部放行」时 Claude 自己进了计划模式：计划卡上点「批准，按当前模式执行」，这一轮回到原来的模式，全局设置不变。
- 切到后台时，跑完或要你确认会发通知。通知里只能拒绝，放行要回到应用看完整命令。
- 在最近任务里把 cccodroid 划掉就是关掉：没有任务在跑时网关跟着停，常驻通知消失，不会再自己拉起来；有任务在跑会接着跑完，跑完再停。定时任务到点照样由系统闹钟叫起来。
- Key 只存在应用私有目录；账户登录由 Claude Code 自己完成，应用不碰凭据。

## 项目与定时任务

**项目**就是一个工作目录，带自己的指令（CLAUDE.md）和默认的型号、思考强度、权限。在项目里开的对话都在这个目录里跑，自动带上它的指令。

- 侧栏「项目」→「新建项目」：在工作区新建目录、用已有的目录，或者从 git 克隆。用已有目录时，以前在那里开的对话自动归进来。
- 新对话的欢迎页上能挑放进哪个项目；输入栏下面会多一个项目标签。
- 已有的对话长按（或点 ⋯）选「移到项目」，会话记录跟着挪过去。
- 对话页的筛选条能按项目看，也能只看定时任务跑出来的对话（带时钟标记）。

**定时任务**到点在本机跑一次 Claude。它没人可问：要它问你的操作一律当拒绝。先用「只读」跑几天，再放权。

- 频率有每天、每周、每月、每隔几小时、仅一次，也能写 cron。表单里会实时算出下次和再下次的时间。
- 想「没事别吵我」：让它没发现时只回一句固定的话（比如「全绿」），通知选「只在有发现时」。
- 能限定只在 Wi-Fi、充电时跑，设单次花费和时长上限，以及每日总上限。第三方接口多数不回报花费，花费上限对它们不起作用。
- 计时在网关里：App 开着或在后台运行时准点跑；被系统清掉、关机时会错过，下次打开按任务的「错过了」设置处理，不会偷偷补跑。

## 脉络

侧栏「脉络」把所有会话画成一张地铁图：横轴是时间，一条线一个会话，按项目分带。竖屏是一棵缩进树。第一次来点右上「怎么看」，两分钟的导览用假数据，不碰你的会话。

- **站和档号。** 会话每压缩一次结束一章，线上画一个站。「a1b2·3」是档号：会话号前四位 · 第几章。点站直接跳到会话里那一章的开头。
- **标题从哪来。** 每章的题名由对话里的模型自己起，用的是这一章实际干了什么，不是第一句话；会话列表显示最新一章的题名。新对话第一轮答完，网关会在后台先起一个，几秒后换上。起名用哪个型号、要不要自动起，在设置「接口与型号」的「自动起名」里改。想换名字，直接跟它说「给这个对话改个名」，或在列表里长按会话自己改；自己改的不会再被盖掉。
- **线的来历。** 从别的线中途岔出来的是分叉，贴着岔口拐下去的是回退，带箭头汇进来的是汇合。没有题名的旧章拿那一章第一句提问灰字顶着，工具栏「补档」能一次补齐。
- **汇合。** 几个会话各做了一半，想合成一个新会话接着干：选中一条线，点卡片上的「汇合…」，再勾上别的会话，点「下一步」。向导分三步：每个来源用压缩摘要还是挑几轮原文，写一句接下来要干什么，最后预览第一条消息（可以在编辑器里改）。发出去后图上从各条来源汇一根线进来。
- **补记来源、从这里分叉。** 卡片「更多…」里：以前手动贴文字交接的会话推不出来源，用「补记来源…」勾上；补错了能撤。「从这里分叉」从这个会话最新的一轮分出一个新会话。
- **档号引用。** 聊天时写「参照 a1b2·3」，发出时会把那一章结束时的压缩摘要附给 Claude（气泡里不显示），一条消息最多认三个。那一章还在进行、没有摘要时，会告诉它会话文件在哪，需要时它自己去读。
- **剖面。** 卡片上的「剖面」把一个会话摊开：一章里每一轮从几点到几点、用了几次工具、派了几个子代理、出错几次，分叉出去的会话挂在那一轮下面，点它钻进去。再点一轮，看每次工具调用（浅色一截是发起前在想，深色是工具在跑）和每个子代理各跑了多久，子代理派的子代理缩进挂在下面。返回键一层层退回来。
- **导出。** 工具栏「导出」把当前这张图存成图片（PNG）、矢量图（SVG），或者能拖能点的单文件网页（HTML），存好后可以保存到别处或分享。

## 文件、终端、浏览器

- **文件与查看器**：代码直接改、直接存；磁盘上的文件被改过，保存前会先问。Markdown、图片、PDF、HTML 直接预览，HTML 改了自动刷新。UTF-16、GBK 编码的文件只读打开，防止存坏。Word、Excel 直接看，PPT 和旧版 doc 第一次用时装一下 LibreOffice。
- **终端**：可以开多个标签；底下一排补上 Esc、Tab、Ctrl、方向键。关掉面板终端照样在跑。
- **浏览器**：地址栏输 `127.0.0.1:端口` 看本机服务；↗ 交给系统浏览器，登录授权页总在系统浏览器里开。

## 大屏与分屏

按窗口宽度自动分档，不看横竖屏：

- 窄：单栏，文件、终端、浏览器盖满屏幕。
- 宽（≥ 840）：对话 + 右侧工作区，分隔条能拖，双击复原。
- 更宽（≥ 1000）：侧栏常驻左边，右边缘也能拖宽。

## 扩展

- **工具包模块**：随装随卸，写明用途、大小、谁在用。终端里敲一个没装的命令，会告诉你在哪个模块。
- **组件**：Chromium、Blender、Godot、LibreOffice、llama.cpp、GPU 驱动这些大件，用到再装。装前核对签名，每个组件自带一个技能，装好 Claude 就会用。
- **常用指令**：扩展页「常用指令」里新建，起个名字（比如 issue），写好要发给 Claude 的话；之后输入框里打 `/issue 具体内容`，后面的内容会填进正文里的 `$ARGUMENTS`。可以存成所有项目通用，也可以只给当前项目。存的是 Claude Code 官方的命令文件，终端里的 claude 也能用。
- **插件、技能、MCP**：在扩展页添加和管理，下一条消息生效。侧栏「更多 → 能力」能看到这一轮 Claude 能用的全部东西。
- **pkg**：终端里 `pkg install rust` 这样装 Termux 仓库的包，`pkg verified` 看实测能用的清单。

## Shizuku 与系统权限

- 设置 → 设备与权限，「一键安装并激活」，经无线调试激活，不用电脑。重启后自己重新激活。已经刷了 **Sui**（Magisk / KernelSU 模块）的，在 Sui 里给 cccodroid 授权就能用，不用装 Shizuku。
- 激活后，终端和 Claude 都能用 `priv '命令'` 以 shell 身份执行，每条都记在「特权命令记录」里。
- **特权命令要你点头**：只有带服务名的 `dumpsys`、`pm list`、`settings get` 这类查看命令直接跑，其余的都会在 cccodroid 里弹框，命令原样摆出来，允许了才执行。cccodroid 不在前台、或者已经有一条在等确认时，直接拒绝，所以挂在后台的任务碰到特权命令会停在那里。几种放宽的办法，从小到大：
  - 「允许，这条命令 10 分钟内不再问」：只对一字不差的同一条命令。
  - 勾上「这个会话后面的特权命令都允许」再点允许：这个会话之后的特权命令不再问，挂后台也能接着跑；应用重启后失效，定时任务不沾光。
  - 设置 → 设备与权限 → 「特权命令不再逐条确认（风险自负）」：所有特权命令直接执行。打开时会弹免责说明，命令写错、模型误判或混进来的脚本造成的损失由你自己承担。
  - 不管哪种放宽，动到 cccodroid 自身和 Shizuku / Sui 的命令会尽量拦下来再问，但拦不住所有写法（比如藏在脚本文件里的）。
- **设备工具**（默认关）：让 Claude 发通知、读写剪贴板、分享文件；读屏和点按要无障碍，可以设成用时自动开。
- **内存管家**（默认关）：跑重活前停掉白名单以外的后台应用。终端里用 `cc-mem run -- 命令`。

## 更新与修复

- **自动更新**（默认开）：Claude Code 静默更新；新版应用核对签名后提醒安装；工具包只在 Wi‑Fi 下预先下载，下次打开时换上。
- 工具包可以从 GitHub、cccodroid.net 镜像或本地文件装，一个源不顺会自动换另一个续传，都按 APK 自带的哈希核对。
- 替换前按发布清单核对，核对不过不动旧版；中途被打断，下次打开接着装完或退回。
- 设置 → 排障里的「修复账本」记着每次安装、校验、修复做了什么。
- **两套安装包**：平常用的 `cccodroid.apk` 是 targetSdk 28，兼容面最广；`cccodroid-36.apk` 是 targetSdk 36，留给系统不让装老 targetSdk 应用的新机器。两套功能一样、数据通用，在 设置 → 更新 →「安装包方案」里随时互换。系统拒装 28 时，应用会记下来、以后只更新 36，这时再选 28 会被拦下。36 版里工具包的程序经系统加载器间接启动，个别按自己所在目录找数据的程序可能水土不服，遇到请反馈。

## 已知问题

- 修好了 · 全部 · **首次打开拼音打不进输入框**：0.3.7 修复。旧版本点一下输入框外再点回来就好。
- 有绕法 · 全部 · **偶尔所有地方都划不动**：系统 WebView 自己的毛病。应用会自动检测，一秒左右恢复，没发的字会填回去；没恢复就长按顶栏的标题（会话名那里）一秒左右，标题变淡、手机轻振一下就开始脱困。
- 有绕法 · 红魔 / 努比亚 · **后台约 90 秒被冻结**：应用信息 → 电池用量 → 后台运行选「允许」，自启动也选允许。
- 有绕法 · 小米 / OPPO / vivo / 华为 · **清后台太狠**：省电策略设成无限制、允许自启动，多任务里把卡片锁住。各家路径见网站的「已知问题」。
- 有绕法 · ZUI · **分屏时提示「不支持分屏」**：系统的分屏黑名单记错了，覆盖安装一次或重启就好。
- 调查中 · 全部 · **顶栏显示「界面脚本出错：Script error.」**：外壳调页面的代码出错时，WebView 只给这一句，看不出是哪里。0.3.13 起会写成「入口名：原因」，截图反馈就能定位。界面一般照常能用。
- 调查中 · 三星 · **打开后一直停在「等待网关…」**：一位群友碰到过，网关其实已经起来了，两三分钟后能进界面，根因还在查。多等一会儿，别反复划掉重开；进去以后到 设置 → 排障 打包诊断发给我们。
- 调查中 · 红魔 · **重新打开应用后新会话报「Failed to fetch」**：网关断了连不上，重启手机后恢复。根因还在查，碰到时到 设置 → 排障 打包诊断发给我们。
- 调查中 · 非骁龙 · **GPU 组件装不了**：大多只支持骁龙；联发科等 Mali GPU 可以装 gpu-driver-mali，Exynos、麒麟暂时不行。

## 排障

先到 设置 → 排障 点「核对记录」，再看「修复账本」。还不行就「打包诊断」发给帮你看的人，或「到 GitHub 反馈」：机型、系统和自检结果会自动带上，密钥和你的消息不会进去。

钩子、插件或 CLAUDE.md 把东西弄坏了，就到 设置 → Claude 行为 打开**安全模式**，自定义的东西一概不加载，关掉就恢复。
