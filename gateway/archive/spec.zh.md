# cccodroid 会话建档规范 v1

你在 cccodroid 里工作。cccodroid 给每个会话建档案：会话每压缩一次，就结束一「章」。会话列表显示的是最新一章的题名，以前的章节在「脉络」里查。题名由你来起，因为你最清楚这一章干了什么。

## 什么时候建档

- 上下文刚被压缩过（你看到了压缩摘要，或系统提示 / 钩子说刚压缩过）：**先**给刚结束的那一章建档，再接着干手上的事。
- 系统提示里说「这个会话还没有题名」：在这一轮最后回答之前建一次档。
- 每次只建一条，一条命令的事，不用向用户汇报。

## 怎么建档

运行（Bash）：

```
node <交档命令路径> --title "题名" [--same] [--misc] [--status 进行中|已完成|搁置]
```

- `--title`：这一章的题名，规则见下。
- `--misc`：整个会话是用完即弃的（测试、试一下模型、打个招呼没干正事）。会归进「杂项」，用户可以一键清掉。有正经工作的会话不要加。
- `--same`：这一章和上一章是同一件事（只是因为太长被压缩切开了）。加上后两章并成一卷，题名以这次的为准。
- `--status`：这件事现在的状态，可省略。
- 命令会告诉你建在了第几章（档号）。如果它退回并说明原因，照着改了再运行一次。

## 题名规则

1. **说清这一章干了什么事**，用动宾结构：「补齐 9 家厂商官方接口」「排查终端密钥 401」「定稿脉络建档规范」。
2. **不超过 20 个字**（英文界面不超过 60 个字符）。
3. **用中文写**（跟随界面语言），专有名词、版本号、命令名照原样保留。
4. **不写**：问候语（你好…）、日期（日期另外著录）、「对话」「会话」「讨论」这类空泛词、emoji。
5. **结尾不加标点**，不加引号、书名号。
6. 一章里干了好几件事：写最主要、最后落定的那一件。

## 例子

| 不好 | 好 |
|---|---|
| 你好，claude | 接手网关修复并验证 |
| 关于工具包的讨论 | 把 which 打进工具包并重验 |
| 2026-10-22 发版 | 发布 v0.3.12 应用内通知 |
| 修了一些 bug。 | 修复首装勾选页按钮在屏外 |
